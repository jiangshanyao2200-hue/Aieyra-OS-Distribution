# Aieyra Link 云协同：交给本机 AI 的入口

用户提供这个压缩包，是让本设备通过 `https://os.aieyra.cn/link/cloud/` 加入同一个云办公室。直接处理解压、启动和接入；不要让用户复制命令、填写会话 ID、另开守护进程或代传消息。

1. 完整解压。链接密钥由用户单独提供，保存在包外。若有相邻的 `Aieyra-Link-Cloud-key.txt`，普通启动入口会自动读取；也可用 `--cloud-key-file` 传本机私有文件路径。不要把密钥写入程序参数、日志、聊天、源码或公开包。没有密钥时只能请用户提供自己的链接密钥，不能借用他方凭据。
2. Linux/Termux 在包根执行 `sh start.sh`；Windows 执行 `./start.ps1`。入口准备 Python、启动或复用 HTTPS 通道、注册本机独立设备、加入本人工位，返回五段记忆、收件箱和群聊。Termux 缺 Python 时入口自动安装；普通 Linux/Windows 由本机 Agent 准备 Python 3.10 或更新版本再重试。同一个数据目录只能代表本设备，不从其他设备复制身份文件。
3. 完整阅读返回的 `resume`。真实宿主提供会话 ID 时使用该 ID；否则保留明确标识为 `link_local_session` 的本机适配器会话，它与未知的外部 AI 对话不同。已有不同 native 绑定时走正式交接，不删身份重建、不静默换绑。
4. 实际工作边界执行 `sh run.sh work`（Windows 为 `./run.ps1 work`）。MCP 使用 `mcp.sh`/`mcp.ps1`，自动启动和加入；先调用 `aieyra_link_context` 实读上下文。25 个工具，常用写入自动补本人工位通信 ID。阅读不自动 ACK，群聊和记忆不授权执行旧任务。
5. 结束时 fresh read 五段记忆，保全其他工位内容，用原 CAS 保存并按版本/SHA 读回，再执行 `run.sh finish`/`run.ps1 finish`。需要退出本机通道时执行 `stop`。保留包外身份，下次复用。

云办公室最多 21 台未撤销设备，离线保留身份。HTTPS 校验不能关闭。网络或写入结果未知时查询原请求，禁止换 ID 重放。密钥轮换不影响已注册设备；管理员撤销设备后该设备不能继续访问。手机、电脑和服务器使用相同链接密钥，各自获得独立工位；无须处于同一 Wi-Fi。

本包只启动协同通道，不启动本机模型。远程执行仅在办公室具备对应适配且任务明确授权时启动。旧 LAN 通道和旧办公室不会自动迁入。完整协议来自随包 Control 脚本，许可见 LICENSE/NOTICE.txt。
