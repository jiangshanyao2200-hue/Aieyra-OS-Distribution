# 独立 Link Go 内核 · 工作协约

遵循[根协约](../../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[go.mod](go.mod)、[client.go](link/client.go)、[bridge.go](link/bridge.go)。

职责：提供独立Link程序需要的Go桥接、任务/决策/协议及命令装配，link/cmd/internal按实际Go包组织。

依赖与接口：与Control正式协议连接；Core/link仍有OS内部消费者，改共享协议需核对两侧而非假设其中一份已经退役。

资料与状态：工位身份/请求/租约来自外部资料，源码和发布包不含私人配置或对话；通信在线不等于执行已恢复。

开发与验收：在本独立模块根串行GOMAXPROCS=1 GOFLAGS=-p=1 go test ./...、go vet ./...并检查gofmt；Control契约与独立Link包实际启动另验。

兼容与交接：保留旧原生入口与来源/许可，确认消费者后才删桥接；未知投递不换ID盲目重发。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
