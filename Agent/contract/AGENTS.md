# Agent 定义任务与实例契约 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[definition.go](definition.go)、[task.go](task.go)、[package.go](package.go)、[instance.go](instance.go)。

职责：校验身份、团队引用、提示词资源、工具/Program/Context 依赖、预算/生命周期及任务验收和回执结构。

依赖与接口：Core 与桌面/CLI 共同消费；契约不访问文件、不授予权限、不执行模型或独立审查。

资料与状态：公共包定义和私人实例覆盖分离；导出只能读原始公共包，不能重建自个人配置。

开发与验收：在 Agent 运行 go test ./contract、go vet ./contract；定义/版本变更验证 Core 准入、旧 JSON 和精确依赖拒绝。

兼容与交接：旧任务 JSON 及工具 ID 保持，未知字段/资源路径/默认工具拒绝；版本切换不能隐式迁移 Context 或数据。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
