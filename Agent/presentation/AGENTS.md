# Agent 只读呈现 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[desktop.css](desktop.css)。

职责：为标准 Agent 包的桌面实例管理与状态提供展示样式，不定义人格、权限或任务事实。

依赖与接口：宿主给出经过授权的实例状态，风格复用 Theme 基础令牌与 Desktop 共同控件。

资料与状态：只呈现当前实例，不在 CSS/DOM 属性中嵌入私人提示词、模型连接或完整历史。

开发与验收：修改后在 Client/Desktop 执行 npm run -s syntax 和 npm run -s selftest；界面变更按 docs/UI协约.md 选择受影响 AIDEBUG 场景，在源码冻结期间实看原生图。 实例创建、停用、切版与团队投影要保持可读和可操作。

兼容与交接：样式不能改变操作权限和真实终态；新增元素通过 Theme 元件/槽位契约接入。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
