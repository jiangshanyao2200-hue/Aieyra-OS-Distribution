tool_factory arguments: action=list returns registered tool names/descriptions; register requires name (lowercase letters/digits/underscore, max40), description (max1000), code (async JavaScript body,max64KiB), schema (JSON Schema subset type:object with properties,required,additionalProperties:false; property types:string,number,integer,boolean,array,object; primitive enum optional), capabilities:[exec_command,write_stdin,read_shell_output,apply_patch,view_image]. Returns immutable custom:name.version ID derived from the full manifest. The code receives const args and the existing tools/text/image/store/load functions. Use text(value), or return a JSON value; a defined return value is automatically emitted. Successful completion without output is not evidence of a correct result. Integer arguments must stay within JavaScript safe integers (abs<=9007199254740991); represent larger exact values as decimal strings with a string schema. JSON args are serialized as data, never evaluated as code. Version changes require registering a new manifest. register does not execute or prove correctness: open the returned custom ID and call with a small reference case, then independently inspect the actual result before assigning it. remove(id) removes an unused version; existing users will receive unavailable. A child assigned a custom ID must also receive every capability it needs to perform its nested operations. The assigned version also exposes wait for its owned continuing cells; arbitrary exec is not required. Use toolbox open(custom ID), call(custom ID,arguments), close when finished. list/open loads only selected documentation; implementation is immutable and not injected into the model prefix. Tool execution is the existing JavaScript orchestrator with durable nested receipts and assigned dispatch limits, not a hostile-code OS sandbox. Optional presentation selects a declarative kind (terminal, reader, search, editor, browser, toolbox, table, cards), title and up to 12 columns [{key,label}]. Data uses existing tool results; no HTML/CSS/renderer scripts. New views require a new immutable manifest version.
每个工具配套声明式 presentation(kind,title,columns?)，支持 terminal、reader、search、editor、browser、toolbox、table、cards。根据实际任务选择视图；终端用 terminal，表格用 table。未提供时工厂按能力补终端或卡片视图。资源中心分享工具时必须显式携带相同视图。注册按内容生成版本 ID，立即可用，旧版本保留以支持正在执行的任务与回滚。
