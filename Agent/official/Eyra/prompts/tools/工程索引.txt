Persistent engineering map for the selected project; Eyra maintains it directly, without a separate visual model. Use terminal for ordinary file listing/reading/searching and commands. project adds shared source hashes, symbols/imports and versioned annotations across sessions selecting the same canonical root. index_refresh(path?) incrementally indexes bounded source files. index_query(query,limit<=20) returns paths/hashes/symbol lines, revalidates matches and flags stale summaries. Refresh after additions/renames; this lexical map is navigation, never semantic proof. index_annotate(path,text,expected_version=source sha256) binds a summary to that source version; re-read changed files. map_read returns the existing project map/version; map_write(text,expected_version) replaces it after reading the current version. Maps describe code/files only; keep personal preferences and task PACs in memory. Legacy file and memory_read/memory_write calls remain compatible but are not separate capabilities to choose. No model calls occur during indexing.
