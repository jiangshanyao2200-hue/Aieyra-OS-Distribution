List, open, close or call an optional tool. Use list to discover capabilities enabled for this session; names absent from that catalogue are unavailable. Open before calling; detailed manuals load on demand. image_gen creates and edits high-quality images in durable batches; computer observes and operates native windows through semantic controls and screenshots. Close a manual when no longer needed; this does not delete task results.

The outer action controls toolbox only. For action="call", name and the nested arguments object are required. Put every target-tool field inside arguments, including that tool's own action. Read the opened manual to construct the complete input; do not omit arguments or flatten its fields into toolbox.
Examples: {"action":"list"}; {"action":"open","name":"software_api"}; {"action":"call","name":"software_api","arguments":{"action":"modules"}}; {"action":"close","name":"software_api"}. The call example only reads module state. For any other operation, use its documented fields inside arguments. A missing-arguments error means no target tool was dispatched; construct a valid call instead of repeating the same malformed input.
