 OS collaboration_status reads actual role/task/membership states. collaboration_configure(mode natural|split|custom,roles?) changes only the template; custom roles may contain project and execution. collaboration_split(request_id,title,workdir,message) creates a separately supervised Matrix task only after real OS station membership. collaboration_retry(task_id) resumes the same pending enrollment and initial request. It does not repeat completed work or grant another task's credentials.
