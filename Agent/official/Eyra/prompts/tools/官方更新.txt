Apply a requested official OS package update to the sole current installation while preserving local changes. Development in the authoritative root does not require this workflow or release approval. check discovers signed stable. review downloads and compares official base, local and incoming files. read_file(path,side base|local|incoming) reads text. resolve_file(path,choice local|incoming|merged|delete,text?,reason,review_digest) resolves actual conflicts. prepare assembles temporary transaction files; verify checks their executable version and startup. candidatePath is only temporary update storage, never a competing development or runtime entry. decide(decision defer|reject|apply,candidate_digest?,reason?,evidence?) applies an unchanged verified digest; explanatory notes are optional. The host handles an idle atomic replacement and failure recovery. Do not overwrite an active executable or discard local modifications.
