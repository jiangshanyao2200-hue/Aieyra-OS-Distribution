# 原生窗口页面 · 工作协约

遵循[根协约](../../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[index.html](index.html)、[renderer.js](renderer.js)、[activity-view.js](activity-view.js)。

职责：承接原生/独立窗口页面与受控投影，旧browser页面仅转接Program的唯一脚本样式。

依赖与接口：通过宿主preload取得公共状态/操作，复用共同主题和生命周期；不读取任意源码或私人配置。

资料与状态：窗口收到旧代投影须丢弃，关闭清订阅和资源；原生窗口不重复播放声音或复制执行。

开发与验收：修改后在 Client/Desktop 执行 npm run -s syntax 和 npm run -s selftest；界面变更按 docs/UI协约.md 选择受影响 AIDEBUG 场景，在源码冻结期间实看原生图。 原生窗口热更新、125%缩放、关闭/恢复和真实PrintWindow图需独立核验。

兼容与交接：旧文档结构为运行中宿主兼容保留，不能恢复第二份浏览器业务或在缓存旧路径时直接删除。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
