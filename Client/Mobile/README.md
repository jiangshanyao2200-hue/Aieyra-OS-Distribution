# 手机客户端边界（未实现）

这里只预留独立位置和接入约定，当前没有手机App、安装包或已验证的手机运行时。

未来手机端复用Core的身份、任务、会话、记忆、包兼容与模型服务，以公共命令/事件契约接入。先评估远程连接同一Core；本地Core或离线混合能力须另行实现与验收，不复制一套Eyra执行逻辑。

移动端负责触控、输入法、前后台生命周期、连接恢复、系统通知及图片/文件选择。会话恢复必须按游标补齐事件，操作按请求编号查询结果；切换前后台不能静默重复执行工具。推送是状态提示，Core仍是任务权威。

主题/工具/程序/Agent导入必须检查明确的mobile呈现和能力要求；desktop兼容或Android CLI编译通过都不能冒充mobile兼容。未知能力保持未支持，手机功能完成后再向共同包服务注册。
