# Theme

主题负责外观配置、布局与组件组合，Core负责真实状态和操作。`runtime/settings.cjs`已承接既有外观存储，`runtime/layout.mjs`在原组件对象上重排布局；`official/default`保存默认外观资产，旧Desktop路径为现有消费者的转接入口。

独立“主题”应用已退役。设置中的媒体选择器浏览背景和头像，复用`runtime/official-library.cjs`的公开目录、账号签名点赞、原图校验与有界缓存。`Client/Desktop/ui/theme-library.mjs`服务设置选择弹窗。个人设置的头像、Eyra头像及背景可选择、自定义、移除或按1分钟至1天定时随机；`media-preferences.cjs`定义个人资料中的可选`mediaRotation`，由宿主定时器按CAS更新。离线保留旧图并退避，用户后续选择优先，本机缓存原PNG；设置中的预览沿原保存动作提交。Mod安装与管理位于“设置 → 扩展”，沿用共同注册表与包协议；后续独立资源浏览由浏览器承接。公共布局、外观令牌和已有用户资源继续保留。

`contract/elements.json`是当前已接入的公共元素、状态与槽位目录。主题的`theme.json`使用`aieyra.theme/1`，通过同一Mod清单检查、导入及启用，再在设置的扩展管理中应用。`SDK/examples/theme-columns`展示不同结构；`theme-blank`为作者空白模板。布局树可以任意嵌套容器、重新排列槽位、定义网格及组件样式。槽位必须完整且唯一；不复制业务节点、不重建任务或草稿，不运行主题脚本。

每个样板里的`style`是CSS属性数据，允许的属性与元素统一列在契约中；不接受私有DOM选择器、脚本或网络资源。正文、思考、工具等组件的原始内容与事件仍由共同状态提供。当前布局接入workspace/live/application/message/tool、独立会话与观察页、原生菜单/提示/窗口标题、紧凑头像/输入及活动栏。原生表面只接收公开外观投影，热更新保留原操作与任务身份，关闭释放订阅。八类内容渲染器、离线媒体资产、用户覆盖的版本合并及目录展示页已接入；默认/分栏主题、原生表面、动效、触摸/系统IME组合及macOS实机分别验证，性能样本不代表全部设备。

外观设置保持原存储路径；独立设置页使用默认结构，保留“移除主题”，原生Ctrl+Shift+F12可恢复默认。停止或更新当前主题包会退回默认，重新应用前不自动覆盖为另一个版本。CLI和Mobile不声明支持桌面布局。

默认令牌和基础控件样式的权威文件是`official/default/ui-foundation.css`。Desktop转接旧路径，Control/Link的精确HTTP路由直接提供权威字节；独立Control导出时复制相同字节，不向Web开放任意源码路径。

文字优先级为用户明确覆盖 → 主题 → 官方默认。`region_overrides`记录用户改过的字段；旧文件只推断与默认不同的值，读取不改原文件。显式选择默认值仍可覆盖主题；清空对应覆盖字段可重新跟随主题。主题只读这些偏好，不改用户存储。UTF-8长度限制在Go和JS两侧一致。

`contract/elements.json`的`workspace_insets`公开当前左右侧栏占用的宽度；桌面适配器提供`--ui-workspace-inset-left/right`，与侧栏共用同一动画长度，关闭为0。自定义工作区应给正文、输入和工具留出这段空间；顶栏可以横跨侧栏。`theme-columns`演示响应式网格及顶栏补偿；作者无需依赖宿主私有变量或重新实现侧栏状态。侧栏本身通过`session-panel/list/row`和`gallery-panel`元素定制。

`renderers`按完整内容版本键选择语义槽位：`aieyra.content.code/1`含`caption/content`，`aieyra.content.quote/1`及`aieyra.content.table/1`含`content`。所有槽位必需且唯一，未知版本拒绝；主题能重排安全容器，不能替换或执行原始文本。`runtime/markdown.mjs`是各桌面消费者共享的安全解析及增量投影；代码、表格及引用保留原语义节点，默认代码标题隐藏，切换和流式追加不重复构造现存文本节点。Markdown中的HTML与图片地址仍只作为非活动内容显示。分栏样板从1.2的三类正文渲染器扩展到1.6的八类内容组件；各类槽位和实际消费者见下文。

`aieyra.content.thinking/1`提供`heading/content`，包括真实可见思考与等待态；Theme只显示已公开文本，宿主注入共同动效策略并在离开时释放绑定。`aieyra.content.tool-result/1`提供`summary/content/details`，由Tool拥有真实状态、错误、表格、完整回执和操作；桌面把受信任主题适配器注入工具呈现，不向工具包授予脚本或主题权限。普通工具摘要、动态包及Workbox详情共用此契约。分栏样板从1.3五类内容扩展到1.6八类，媒体与展示页入口见后文。

`assets`（Theme契约1.1）将图片与字体作为独立命名资源：`{paper:{path:"assets/paper.png",mime:"image/png"},text:{path:"assets/inter.woff2",mime:"font/woff2",fallback:"sans-serif"}}`。在公开属性中用`background-image: asset(paper)`或`font-family: asset(text)`；不在令牌里嵌入资源引用。支持PNG/JPEG/WOFF2；单文件8 MiB、总24 MiB，图片单边4096、总16M像素，字体解压声明总32 MiB。Core校验图片完整解码及字体容器，Chromium再清洗字体表；失败使用基础背景或通用字体。当前选中且启用的精确包版本才可提供资源，停用/更新/切换撤销新请求，设置页不应用主题。`SDK/examples/theme-assets`含离线纹理、字体许可及完整清单。Theme图片资源不支持SVG；音视频预览与WAV声音事件已接通，具体边界见后文，不开放任意URL或脚本。

`aieyra.content.image/1`将图片查看器的原始`heading/content/controls`交给主题：标题及编辑/引用/定位/关闭按钮、可平移缩放的图像视口与错误重试、切图/缩放栏分别保持原节点与事件。打开时绑定，关闭时释放；主题切换不重新解码或重置缩放。`aieyra.content.attachment/1`提供原始`name/metadata`文本槽位，容器只能是`span`，保持原预览与移除按钮的可访问语义。草稿附件和已发送附件共用标签呈现；移除/替换/清空消息时递归释放主题绑定和对应样式，不等待垃圾回收。分栏样板1.4起展示这两类媒体组件；1.6补音视频，Theme1.4补声音事件，组件展示页见后文。

主题修改独立存为`theme_profiles`，按包ID保留当前默认定义、最初默认版本、上一包版本及所有尚被覆盖或撤销记录引用的原始定义。令牌逐项合并，styles整体合并，布局和内容渲染器按完整树合并；身份和资源声明来自原包。重新应用新版时，未改字段跟随新版，本地修改保留；同一字段两边都变化会显示原默认值、我的修改与当前默认值。编辑其他字段不隐式确认冲突。资源被移除等导致组合无效时保留原修改并暂用当前默认主题；修复或恢复对应字段后继续应用。

共享外观API的`theme_edit`支持`edit`（完整definition）、`resolve`（path及mine/default）、`reset`、`undo`，与其他外观修改共用版本CAS。撤销切换最近两份修改快照，重新合并到当前包版本，不回退包或文字偏好。移除/停用主题保留修改，再次应用可继续。设置页提供令牌编辑、完整定义、冲突选择、默认恢复和撤销；后台刷新保留未保存草稿，遇到版本变化须显式载入已保存版本。最多16个主题、每主题512项覆盖、全部记录1.5 MiB、完整文件2 MiB；超过限制拒绝写入，读取不改原文件。原生表面只接收生效外观，不携带历史记录。

Theme契约1.2的`presets`允许作者提供最多16个命名布局：`{compact:{name:"紧凑",values:{tokens:{"--ui-accent":"#abcdef"}}},reading:{name:"阅读",extends:"compact",values:{layouts:{message:完整槽位树}}}}`。`values`只能改变tokens/styles/layouts/renderers，null明确删除；布局和渲染器仍须完整保留语义槽位。继承最多8层，循环、未知父项、未知属性或无效最终布局拒绝准入。分栏样板1.5提供紧凑消息和继承它的宽栏阅读。

用户预设保存在共享配置的`theme_presets`。保存的是已提交修改，可继承已有预设；父项以不可变快照保留，重命名或删除另一个本地预设不会影响子项。应用预设替换当前主题修改，可通过撤销恢复；匹配同一包ID的新版时仍按预设原始默认版本合并并展示冲突，不改包版本、资源声明或独立文字偏好。包内预设的新版变化须再次显式应用，用户先前选择不会被更新自动覆盖。

“导出预设”保存`aieyra.theme-preset/1` JSON，只包含所选预设、继承链及各层引用的主题默认定义；不带其他预设、撤销历史、个人资料、文字偏好或凭据。媒体字节仍由原主题包提供，预设不能替代主题包安装。导入仅登记，随后由用户选择应用；损坏、超过512 KiB或不兼容记录不写入。共享`theme_preset`命令有save/import/apply/author/delete，保存与应用共用外观版本CAS；文件选择及写入只在桌面宿主。用户最多保留32个预设、总512 KiB，超过配置总预算也明确拒绝。格式见`Contracts/theme-preset.schema.json`。


音视频预览使用 `aieyra.content.media/1` 的 `heading/content/controls` 槽位。Desktop宿主只交付归属当前配置、长度与SHA一致的32MiB内附件快照；WAV/WebM/MP4容器识别后由Chromium解码，格式损坏或编解码器不支持可重试，原附件保留。发送仍为普通文件，不将本地播放宣称为模型音视频能力。主会话和独立会话共享播放器，显式播放、暂停、定位、静音，默认不自动播放；隐藏暂停、关闭撤销Blob并卸载媒体。受支持的Desktop使用保留状态的DOM移动，在换主题时保留原播放器和播放位置。分栏1.6要求Theme ^1.3.0。声音事件和目录展示页见下文；展示页的布局样例不代替真实窗口验收。

Theme 1.4 支持声明 `sounds`：`task.completed`、`task.failed`、`attention.pending` 分别引用同包 `audio/wav` 资产 ID。资产限完整 RIFF PCM、16 位、单/双声道、8–48 kHz、最长 3 秒，字节/时长/对齐均在 Core 准入时核验；不接受网络声音和脚本。示例见 `SDK/examples/theme-sounds`。作者绑定随包版本保存，不由布局预设或个性覆盖改写。

声音开关和 0–100 音量属于独立外观配置，默认关闭。只有主工作区拥有播放器，原生投影和独立窗口不重复播放；按当前会话/运行代次识别新事件，初始快照、重开、重复或过期状态不重放。取消无完成音，同时事件按失败、待回答、完成优先级合并，至少间隔 1.2 秒且不排队。隐藏、切换会话/主题、关闭开关和卸载立即停止；无法播放时保持静音且不自动重试。GUI自动化可验证解码和生命周期，不能代替实际听感验收。

资源中心“组件与状态”展示当前外观；已安装主题详情“预览组件”展示包默认效果，包括未启用的包。预览不写外观配置，恢复默认和关闭位于隔离框架之外。资源由宿主核验已安装摘要与兼容性后提供限时快照，五分钟到期，关闭、隐藏、替换或窗口销毁撤销；每个窗口最多一个预览。包定义不执行代码，预览凭据不能保存为主题选择。

展示页提供控件/输入、真实共同正文与思考、工具回执/工作流、只读终端、图片/静音音频、导航/浮层，以及每个公开布局的槽位样例。状态选择改变真实 native/ARIA/data-state 属性；悬停、焦点和按下需要实际指针/键盘。全部内容标为合成示例。元件计数是当前目录的渲染覆盖，不代替真实业务、原生窗口、多端、性能和辅助输入验收。作者组件模板见 `SDK/examples/theme-components`，保留八类原始语义槽位；新业务组件仍需版本化契约及消费者。
