# 主题组件与状态展示 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[catalog.mjs](catalog.mjs)、[fixtures.mjs](fixtures.mjs)。

职责：展示元件、状态、八类内容与公开布局样例，使用真实共同渲染器与明确的合成内容。

依赖与接口：目录来自 Theme/contract，宿主受限预览服务验证包摘要与资源，展示页不授予执行权限。

资料与状态：预览不保存主题选择；关闭、隐藏、替换或到期撤销资源，单窗口有界。

开发与验收：修改后在 Client/Desktop 执行 npm run -s syntax 和 npm run -s selftest；界面变更按 docs/UI协约.md 选择受影响 AIDEBUG 场景，在源码冻结期间实看原生图。 核对目录与样例一致、状态语义、键鼠焦点和页面收起恢复；展示计数不代替所有业务页面覆盖。

兼容与交接：新增业务组件必须先有版本槽位与消费者，不能仅在展示页画一个相似静态块算接入。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
