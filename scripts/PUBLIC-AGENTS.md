# Aieyra OS · 开发协约

有界代码上下文、可核验任务接续与真实观察分诊见[AI开发工具](docs/AI开发工具.md)；输入原话和运行证据留工程外，工具只记录和核验，不执行任务内容。先核提供的工具及源码范围，缺失项不能当已经可运行。

长期协作先读[长期协作开发](docs/长期协作开发.md)与[程序标准链路](docs/程序标准链路.md)。任务原文和执行/接续表先落私人文档，稳定经验写最近AGENTS；按当前任务→目录CODEMAP→相关链读取，历史不重复装载。代码顶部AI-CHAIN由`scripts/code-atlas.py`维护，人工链在`Contracts/code-chains.json`；改动后refresh/check，用show/chain查询。签名、兼容、生成载荷不因注释整理改字节，静态候选不是完整调用图或验收。单文件按职责集中，复用同时包括身份、权限、状态、主题、取消与恢复。

先读 [开发指南](docs/开发指南.md) 与 [工程地图](docs/工程地图.md)，修改模块时读取最近的 AGENTS.md。地图区分实际实现、兼容入口与仅有契约；文件存在不代表功能已经验收。

Core 负责权限、执行、取消、事件、会话、记忆和持久提交；客户端提供交互与平台能力。API、Tool、Program、Agent、Context、Theme 和 Halo 按公共契约分责。变更接口同时核对调用者、旧版本兼容、资料归属及交付清单，复用既有服务。

源码树用于开发，个人资料放在树外。检查使用临时合成资料，不直接打开真实用户 SQLite，不为验收改写私人配置、凭据、四层提示词或聊天，不关闭使用者实例。公共文案归所属 Agent 或 Tool，见 [提示词目录](docs/提示词目录.md)；旧私人布局只作兼容，不能复制进公开包。删除旧文件前先查消费者，卸载代码不连带删除资料。

原“桌面模式”已移除，桌面客户端源码为 `Client/Desktop`；根 `Desktop` 仅按精确清单保留兼容资源。协作者明确文件范围，构建与 GUI 验收串行，实际验收期间冻结受测源码。临时脚本、日志和截图放工程外。Go 重检查使用 `GOMAXPROCS=1`、`GOFLAGS=-p=1`，Python 使用 `-B`。只重跑受影响检查，失败原件保留，未验范围如实记录。

行为提示词由使用者可编辑的四层外部文件提供；源码只维护运行身份、工具/数据协议和必要的权限、取消、事务校验。公共默认与私人覆盖分离，不把私人正文写入文档或包。

新增模块同步就近协约、工程地图、公开文档精确清单和受影响测试。公开导出必须通过严格隐私与导航检查，不扩大目录白名单补缺。签名包文档变更需要同步载荷清单与宿主认可摘要。正式发行由官方签名，本地构建不代表已发行；发布、生产操作、对外通信与真实供应商调用服从明确授权。
