# 构建导出与安装工具 · 工作协约

代码链导航归code-atlas.py：从原模块地图/就近协约与人工链生成自有代码顶部目录、目录CODEMAP和可查询索引，改动后refresh/check。正文、编码/编译前导、签名/兼容载荷必须保留；只导出精确列出的公共地图，私人接续和任务原文不进入清单。新增路径/依赖与源码变化必须使旧导航失效；符号/静态导入候选不能当完整调用图。

保护生成资源须识别Code generated、DO NOT EDIT和注释中的Generated by/from；不能把导航头写进精确生成契约。实际曾因Theme/contract/elements.mjs被加头而使Desktop syntax的生成一致性检查失败，恢复原生成字节并核重复refresh后仍一致。地图check通过不能代替原生成器检查或产品syntax。

AI入口见[AI开发工具](../docs/AI开发工具.md)。context输出共同所有者/祖先协约/影响与验证候选，绑定全索引库存和读取规则；预算不足失败，不截断约束。development-session只在工程外保存追加检查点，更新核head，保留全部原文/工作/失败/资源/证据引用；resume返回原话、下一步、漂移与待核资源，不执行动作。证据漂移不能靠删除引用规避；source更新和历史context必须显式区分。检查点链不认证作者，尾部丢失依靠接续点保存的head核对。

遵循[根协约](../AGENTS.md)；当前职责与迁移边界见[工程地图](../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[build-windows.py](build-windows.py)、[check-modules.py](check-modules.py)、[public-privacy.py](public-privacy.py)、[runtime-files.py](runtime-files.py)、[development-docs.py](development-docs.py)、[开发文档精确清单](../Contracts/development-documents.json)。

职责：维护Windows/Linux/macOS构建、四产物与模块启动器、公开源包/Link包、平台安装、签名元数据和依赖/隐私/UI检查；link/plugins/ui-contract按各自脚本接口工作。

依赖与接口：消费Contracts/product-layout和resources公共选择器；构建/更新器需同源，不自行猜新增模块路径或扫描私人资料。

开发文档：源码导出及Windows/macOS软件包使用同一逐文件清单。公开根协约/导航从PUBLIC模板生成，原工程地图保持完整，交付投影注明未提供文件；不纳入私人台账，不通过递归开放docs或AIDEBUG补缺。签名包Markdown逐字节保留；缺载荷或摘要变化即停止导出。修改选择器同时核实际源码、完整运行包和独立Link清单。

资料与状态：临时构建/证据在工程外；runtime锁、许可、资源摘要是来源证据，不能当缓存删掉。正式发行由用户决定。

开发与验收：Python-B；改脚本先看--help及对应测试，重构建串行。文档变动用路径/链接/范围和隐私检查，不为不受影响的源码重复全量构建。

兼容与交接：只在唯一主工程直接构建，候选/guard/晋升已取消；源码、构建产物、运行进程和实际验收分别记录。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

build-provenance的begin在创建收据前复用development-docs的包载荷校验，直接比较已采集的公开来源SHA256/size，不重复读取载荷或追踪清单扩展私有路径。清单从同次普通文件读取有界捕获；失败不重写清单、旧收据或EXE。此预检仅核公开声明载荷，签名、官方身份、语义与兼容准入仍由Core负责。
