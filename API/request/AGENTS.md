# 模型请求编码 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[chat.go](chat.go)、[responses.go](responses.go)、[native.go](native.go)、[images.go](images.go)。

职责：把公共消息编码为 Chat/Responses/Anthropic/Google 请求，保留工具批次、图片顺序和同供应商原生续接。

依赖与接口：只接收 Contracts 消息、参数和已验证图片字节；路径读取与供应商选择属于宿主。

资料与状态：不同供应商不沿用不透明签名；序列化不修改共享消息和参数，不重复读取附件。

开发与验收：在 API 运行 go test ./request 与 go vet ./request；验证系统消息、连续工具结果、多图、跨供应商签名及数字原样。

兼容与交接：保持 false/0 和字段存在性；不能为“通用化”丢失供应商原生信息或工具调用 ID。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
