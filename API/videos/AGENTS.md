# 视频供应商协议 · 工作协约

遵循[根协约](../../AGENTS.md)，入口为[client.go](client.go)。

职责：实现已核实的Muse JSON创建、同源任务查询与无凭据媒体下载。输入和结果类型来自Contracts/protocol，API不读取用户配置、任务档案或本地文件；Core负责持久任务、准入、取消本地等待、恢复和产物校验。

创建前必须持久化未知提交状态，收到成功HTTP响应后先保存原回执再解析。调用只发一次，不以Idempotency-Key承诺上游去重。公开task ID始终绑定原BASE；禁止用管理员渠道头或直连上游兜底普通查询。轮询失败不丢弃原ID，不发第二次创建。

只支持已确认的文本生成参数，seconds字符串与duration整数一致；画幅和时长均是提示。参考素材、remix、删除与远端取消尚未验证或未实现，不开放。下载不带Bearer/Cookie，限制HTTPS、重定向与大小，URL留私人回执，不能泄入模型摘要。

验收在API串行运行go test ./videos和go vet ./videos，覆盖真实HTTP请求字段、未知提交、持久回执失败、ID混淆及下载凭据边界；随后验证Core持久任务和产物检查。本地夹具不能代表真实Muse或聚合层已通过。真实供应商的创建、查询和下载分别记录实际响应，故障不自动切换管理渠道。
