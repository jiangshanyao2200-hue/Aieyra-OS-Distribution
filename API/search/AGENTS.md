# 原生联网搜索协议 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[search.go](search.go)、[search_test.go](search_test.go)。

职责：拥有供应商选择、原生搜索请求、来源解析与明确不支持时的后备策略。

依赖与接口：Core 授权并注入后备函数，Tool 负责手册/工具回执；此层不运行 DDGS 或读取私有配置。

资料与状态：联网能力须匹配来源和协议，普通回答不能伪装成已搜索；凭据不随重定向发送。

开发与验收：在 API 运行 go test ./search 与 go vet ./search；验证来源、取消、错误分类和后备条件，实际联网结果另验。

兼容与交接：保留精确网址与来源身份，只有明确不支持才后备，超时和未知结果不触发隐式重复请求。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
