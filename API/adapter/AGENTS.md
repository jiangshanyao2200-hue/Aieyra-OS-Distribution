# 声明式 API 适配 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[definition.go](definition.go)、[api-adapter.schema.json](../../Contracts/api-adapter.schema.json)。

职责：定义 aieyra.api/1 的附加路径、静态非凭据头、型号别名和有界额外参数，复用现有四协议。

依赖与接口：Core 共同 Mod 服务校验并锁定包摘要，transport/request/codec 消费准入快照；不执行作者脚本。

资料与状态：绑定属于模型连接，公共包没有服务器凭据；路径只能附加到用户已有 Base URL，认证仍由连接层提供。

开发与验收：在 API 运行 go test ./adapter；集成查 Core 的 API 绑定测试和 Desktop 模型诊断消费者，覆盖停用、升级、回滚、损坏与内置恢复。

兼容与交接：包更新不自动改绑，参数/缓存证据按摘要隔离；新增 wire 协议仍需独立实现与验收。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
