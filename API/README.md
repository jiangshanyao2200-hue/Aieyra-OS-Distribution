# 模型 API

独立 Go 模块 `github.com/aieyra/aieyra-os/api`。`transport` 承接所有现有模型协议共用的连接、禁止重定向、超时、请求头、会话身份与缓存键、错误解析/分类和可选诊断。`codec` 承接 Chat、Responses、Anthropic、Google 的流式解析、响应装配、工具身份校验和真实用量；只依赖 `Contracts/protocol` 公共消息与事件。Core 持有配置快照，仍负责重试的提交边界、工具与任务生命周期；API 不依赖 Core、桌面或私人配置路径。

当前调用：`Core.New` → `transport.NewClient`；Chat、Responses、Anthropic、Google 使用同一连接策略。模型 worker 经同一 SessionID 传递角色会话；供应商能力控制是否发送缓存键，不把稳定键当缓存命中证明。`APIError` 由此模块定义，Core 的类型别名保持原调用兼容。

`AIEYRA_PROVIDER_TRACE` 显式开启诊断后记录请求/响应正文，不记录请求头，单文件最多 8 MiB。正文可能含用户内容，目录由调用者选择；正式默认关闭。

`codec.NewResponseDecoder` 接收逐个 SSE 事件，保留输出顺序、思考与正文的实时状态；只有完整响应通过校验后才产生可执行工具消息。Core 的兼容函数只转交调用；跨模块测试使用公共解码器入口，不再操作解析器内部字段。

`request` 负责四协议消息编码、同供应商原生续写、更换供应商后的签名隔离、连续工具结果和图片排列。`parameters` 负责参数值/路径检查、厂商思考字段、已审定规则与通用映射；保留显式 false/0 和供应商默认选择。Core 从活动配置及模型目录中选择规则、校验来源，传入快照；目录数据加载和配置持久化仍归宿主。

图片由宿主在构造请求时读取并检查哈希、尺寸和字节预算，作为 `request.Image` 传入。API 不访问附件路径；重复序列化不重新读取文件。Chat 先合并开头 system，再安排图片位置，连续 tool 结果之后统一追加图片观察。不同请求拥有独立的参数副本，会话缓存键不会写回共享配置。

`catalog` 解析宿主提供的模型目录，按渠道、原生型号与协议查询能力/参数规则，校验已审定入口；返回值与共享目录分离。Core 保留文件加载、缓存、配置迁移与持久化。`transport.NewRequest` 统一四协议路由、JSON请求体、鉴权与流式头；宿主提供已验证的连接快照和取消上下文。

`images`承接生图/编辑HTTP协议、多段表单、稳定请求ID、响应上限与无凭据下载；宿主注入图片字节校验。每次调用先保存未知用量，付费原始回包先保留再解析；未知结果、重定向和损坏回包不自动重试。图片输入是已读取字节，API不读取本地参考图或私人配置。

运行 `go test ./...`、`go vet ./...`。模块文件纳入共同产品交付清单；Windows 成套构建从该清单找到独立 Go 模块并检查格式、vet及适用单测。第三方声明式适配器经共同 Mod 注册器导入与启用，需分别验证兼容性与实际调用。

`search`承接原生联网搜索的供应商选择、请求编码、有界HTTP、来源解析和明确不支持时的后备策略。识别仍要求官方来源及匹配协议，禁止携凭据重定向；API不读取配置或运行本地搜索程序。后备函数由宿主授权后注入，普通回答不能当作联网凭据。

`adapter` 定义 `aieyra.api/1`：同一规范协议下的路径、静态厂商头、型号别名和有界额外参数。路径只能附加到用户配置的 Base URL，不能定义其他服务器、凭据或脚本；认证与会话头仍由连接层提供。原生消息、工具调用ID、流式状态和usage继续由同一request/codec验证。大整数原生字段按原数字编码保留；作者默认不会覆盖用户已经指定的值。

`SDK/examples/api-local-gateway` 是 Responses 网关样板。资源中心导入并启用后，在包详情选择兼容模型并「应用到模型」；绑定保存在该模型的 `adapter_package`，只记录包ID与精确摘要。升级不会自动替换绑定，停用/损坏拒绝新调用；回滚或重新启用原摘要后可以恢复，或显式「恢复内置适配」。角色/工作流/CLI通过同一Core请求消费。工作进程只接收父进程准入的声明快照，不获得完整配置与其他凭据。

资源中心「测试模型响应」使用同一Go请求与解析，最长30秒、最多4096输出token。设置服务的模型测试、参数探测和工具/缓存诊断遇到绑定时，通过有界子进程使用同一Go传输和共同包准入；每次核对保存的模型身份与精确摘要，关闭输入会取消HTTP，不自动重试。模型列表测试保留已有配置的协议与绑定，绑定后不跨协议后备。临时凭据包含精确适配身份。参数被接受不等于语义支持，缓存只显示实际报告值。样板使用本机夹具验收，不表示真实网关已认证，也不表示作者能动态添加第五种wire codec。

参数探测缓存按连接地址、型号、协议及适配包ID/摘要隔离。切换绑定时保留用户参数值和可编辑规格，移除旧绑定的探测证据；回滚可读回对应版本缓存。旧内置适配的缓存继续可读，但不能作为新绑定包的验证依据。

视频协议由[videos](videos/AGENTS.md)持有，输入/结果类型在Contracts/protocol/video.go。Muse创建只发一次JSON，seconds和duration一致；原公开ID只向原BASE查询。回执先持久再解析，下载不附凭据。Core持久任务及工具入口接入中，真实供应商未验，不能据协议夹具认定完整视频功能已交付。
