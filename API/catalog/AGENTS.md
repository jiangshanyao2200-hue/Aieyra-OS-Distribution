# 模型目录查询 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[types.go](types.go)、[query.go](query.go)、[endpoints.go](endpoints.go)。

职责：解析宿主提供的模型资料，按渠道、原生型号、协议查询能力与参数规则。

依赖与接口：不依赖配置持久化或联网发现；宿主负责加载、缓存和来源审定，返回独立快照。

资料与状态：目录能力只是声明与已记录证据，不替代当前供应商真实响应；不包含 API Key。

开发与验收：在 API 运行 go test ./catalog 与 go vet ./catalog；覆盖不同渠道同名型号、别名和未知能力。

兼容与交接：保留型号原文与能力来源，不能仅按显示名合并连接或借用其他版本的验证证据。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

Muse 代理能力只绑定官方网关 fast.aieyra.cn/v1 的精确型号 muse-spark/image/video；不借用 OpenCode muse-spark-1.3-contributor 的工具、视觉或缓存证据。导入扩展地址不是推理端点。文本按纯聊天能力登记，容量未知；媒体类型不能担任对话角色。视频当前参考可见、提交入口待完善；普通网关查询故障不能用管理员指定渠道绕过。
