# 连接与错误边界 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[client.go](client.go)、[request.go](request.go)、[errors.go](errors.go)。

职责：统一 HTTP 客户端、禁止凭据重定向、路由/认证头、超时取消、错误分类和有界诊断。

依赖与接口：接收宿主验证的连接快照与请求体；不读取配置文件，不决定工具/模型重试提交。

资料与状态：会话身份及缓存键按能力发送；缓存键稳定不等于命中，日志不带认证头。

开发与验收：在 API 运行 go test ./transport 与 go vet ./transport；覆盖取消、响应上限、重定向、错误体和并发参数隔离。

兼容与交接：四协议共用连接策略，适配包不可覆盖认证和会话头；真实网络结果另验。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
