# 图片供应商协议 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[generator.go](generator.go)、[request.go](request.go)、[usage.go](usage.go)。

职责：处理生图/编辑 HTTP、多段表单、稳定请求 ID、下载上限和真实图片用量。

依赖与接口：Tool/imagegen 与 Core 注入模型/输入字节和图像校验；API 不读取本地参考图或相册。

资料与状态：调用前记录未知用量，付费回包先保存再解析；无凭据下载，禁止携凭据重定向。

开发与验收：在 API 运行 go test ./images 与 go vet ./images；损坏回包、未知副作用、下载失败和多段表单使用有界夹具，真实生图另验。

兼容与交接：重试不得重发未知付费请求；响应回执与用户图片原件保持，不能用静音/合成图当真实供应商验收。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

Muse 图片适配沿用生成器与付费回执，每请求单张、URL返回、同入口并发1；尺寸仅提示词引导，格式/尺寸信文件检测，下载不附Bearer。编辑与遮罩当前拒绝提交；上游零用量或网关估算不记为真实供应商用量。本地模拟通过与真实供应商验收分别记录。
