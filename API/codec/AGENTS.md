# 模型响应解码 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[responses.go](responses.go)、[chat.go](chat.go)、[native.go](native.go)、[types.go](types.go)。

职责：解析四协议流、装配完整响应、验证工具身份与参数，输出正文、公开思考、usage 和终态。

依赖与接口：依赖 Contracts/protocol；Core 兼容入口只转交，客户端不另写 SSE 业务解析。

资料与状态：只有完整校验的工具响应才可执行；尾帧、空正文、未知用量和非 JSON 元数据保留实际语义。

开发与验收：在 API 运行 go test ./codec 与 go vet ./codec；双轮工具、坏参数、尾帧、断流、思考转正文和用量存在性均需覆盖。

兼容与交接：事件编号和状态顺序为公共契约，不能把流结束或 HTTP 200 直接当任务成功。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
