# 模型参数规则 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[values.go](values.go)、[paths.go](paths.go)、[profile.go](profile.go)、[catalog.go](catalog.go)。

职责：检查参数值/路径并应用厂商思考字段、通用映射和经过审定的规则。

依赖与接口：接收宿主选出的目录规则快照；连接持久化和探测证据归 Core/Desktop，不在参数包访问文件。

资料与状态：区分用户指定值、厂商默认、显式 false/0；不把“HTTP 接受”直接记为语义能力。

开发与验收：在 API 运行 go test ./parameters 与 go vet ./parameters；核对值域、默认/显式值、思考预算和嵌套路径。

兼容与交接：新增模型映射不得静默覆盖已有用户值；探测缓存须由消费者按连接/协议/精确适配摘要隔离。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
