# 公共文本隐私边界 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[text.go](text.go)。

职责：提供各消费者共享的文本隐私处理基础，避免不同界面各自猜测脱敏。

依赖与接口：只处理输入文本，不读取配置、扫描用户目录或决定出站发布。

资料与状态：脱敏不是公开授权；私人会话/提示词仍留在本地，出站内容须按实际接口授权。

开发与验收：在 Contracts 运行 go test ./privacy 与 go vet ./privacy；公开导出仍走 scripts/public-privacy.py，不因使用此函数跳过检查。

兼容与交接：修改规则保留来源语义与必要标识，不能通过忽略命中让公共扫描“通过”。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
