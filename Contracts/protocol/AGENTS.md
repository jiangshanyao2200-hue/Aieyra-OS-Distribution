# 消息与事件公共类型 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[types.go](types.go)、[model.go](model.go)、[snapshot.go](snapshot.go)、[terminal.go](terminal.go)。

职责：作为 Core/API/Tool/CLI 共用的消息、模型事件、工具定义、用量、附件与终端接口源；旧 Core 类型仅保留兼容别名。

依赖与接口：只依赖标准库或契约内类型，不负责 HTTP、执行或 UI。

资料与状态：快照深拷贝嵌套工具参数、原生签名、图片与非 JSON 元数据；缓存未知与零命中用字段存在性区别。

开发与验收：在 Contracts 运行 go test ./protocol、go vet ./protocol，并回归受影响 API/Client/Core 消费者。

兼容与交接：事件号、JSON 字段、工具 ID 与值存在性保持；新字段必须检查所有序列化/快照路径。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
