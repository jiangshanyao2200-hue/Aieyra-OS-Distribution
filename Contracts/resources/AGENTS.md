# 提示词资源索引 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[prompts.go](prompts.go)、[prompts.cjs](prompts.cjs)。

职责：提供逻辑提示词名到模块公共文件的共同解析，两种语言保持相同入口。

依赖与接口：宿主加载 Config/提示词索引.json 并处理私人覆盖，资源契约不决定 Agent 权限或行为。

资料与状态：公开默认与个人四层分离；已有空个人文件属于显式覆盖，备份不当作默认资源。

开发与验收：在 Contracts 运行 go test ./resources；修改索引或公开文案同步核对宿主编辑器、公共隐私哈希与旧位置覆盖测试。

兼容与交接：不得通过重置或目录迁移覆盖私人四提示词；索引失效显式报错，不静默读另一用户资料根。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
