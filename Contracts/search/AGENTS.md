# 搜索结果公共类型 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[result.go](result.go)、[text.go](text.go)。

职责：规定可追溯来源、结果与文本投影，API 原生搜索与 Tool 的后备路径共享。

依赖与接口：不发网络请求、不运行本地搜索进程、不读取配置。

资料与状态：保留来源 URL、标题与实际结果，不把模型自由回答包装成联网证据。

开发与验收：在 Contracts 运行 go test ./search 与 go vet ./search，并验证 API/search 与 Tool/web_search 消费者。

兼容与交接：字段变化同步双端呈现与模型工具回传，来源精确性和错误语义保持。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
