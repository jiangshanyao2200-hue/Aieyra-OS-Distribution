# 内容组件扩展模板

复制到作者工作目录后更换 manifest.json 的身份、作者和版本。theme.json 通过公开 renderer schema 重排八种组件的原节点；每个槽位恰好一次。附件为行内 span，其他组件可使用已允许的容器。原始表格、代码、媒体节点、按钮和事件不复制、不替换。

运行 `node SDK/tools/package.cjs <目录>` 更新摘要，再由资源中心导入。在“已安装”的详情点“预览组件”，无需启用或应用；对话场景检查代码、引用、表格和思考，工具场景检查结构化回执，媒体场景打开图片与音频。外层状态选择器和恢复按钮不受预览主题影响。示例不是实际模型输出，也不代替原生窗口验收。

主题只能使用 Theme/contract/elements.json 中的元素、状态、属性、布局和 renderer 槽位。不接收脚本、私有选择器、任意 URL 或宿主调用。新增业务组件须先注册版本化契约和真实消费者；仅在 JSON 写新名字不会自动创造组件。布局和字体请检查窄宽、减少动效、键盘、长文本，以及切换时草稿/选区/播放位置连续性。
