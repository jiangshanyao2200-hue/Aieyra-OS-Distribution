Theme assets example

The original 64px texture is MIT licensed. Inter is bundled under FONT-LICENSE.txt.
Declare PNG/JPEG or WOFF2 files under assets; use asset(paper) in background/background-image and asset(text) in font-family. Arbitrary URLs, SVG, scripts and font local() are unavailable.
Files are limited to 8 MiB each and 24 MiB together; images to 4096 pixels per side. Font tables are sanitized by Chromium and fall back to the declared generic family. Switching, disabling and restarting use the exact package digest.
