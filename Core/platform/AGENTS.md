# 路径与平台基础 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[paths.go](paths.go)、[layout.go](layout.go)、[config-file.cjs](config-file.cjs)、[profile_processes.go](profile_processes.go)。

职责：提供配置/资源/资料根解析、平台进程识别与共同配置文件锁/CAS，Go 和桌面调用同一布局规则。

依赖与接口：依赖 Contracts/storage 与公共布局；不导入业务执行器，不为每个客户端复制目录算法。

资料与状态：解析本身不是创建、搬迁或删除授权；显式不可写工作目录必须报告失败，默认回退按现有策略处理。

开发与验收：在 Core 执行 go test ./platform、go vet ./platform；JS 锁与路径消费者用 Desktop 自测，覆盖外置配置、旧布局、只读安装根及链接拒绝。

兼容与交接：路径迁移必须兼容旧绝对引用并保留原件；不得把合法但不可访问的路径默认为另一份空资料。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
