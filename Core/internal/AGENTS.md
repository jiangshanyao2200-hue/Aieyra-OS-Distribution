# 内部原子文件与所有者租约 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[snapshot.go](privatefile/snapshot.go)、[file.go](privatefile/file.go)、[lease.go](osowner/lease.go)。

职责：privatefile 提供私有原子文件与 Windows 可替换快照，osowner 提供进程所有者租约；为 Core 内部基础设施，不暴露业务调度。

依赖与接口：消费者在 Core 内注入路径与权限。不要把普通 Write 和允许旧读者持有快照的替换语义混为一谈。

资料与状态：旧读者看完整旧字节，新读者看新版本；租约与暂存文件由拥有者释放，不能全目录清理。

开发与验收：在 Core 执行 go test ./internal/...、go vet ./internal/...；文件共享/替换与进程锁必须覆盖目标平台。

兼容与交接：保留锁失败和回执，拒绝跟随链接越界；不要为一次测试放松原子替换或活动写者保护。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
