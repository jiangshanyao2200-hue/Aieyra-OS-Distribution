# 共同记忆事务 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[history.go](history.go)、[pac.go](pac.go)、[lookup.go](lookup.go)。

职责：提供 SQLite 事务、长期记忆、完整原文投影、检索纠正遗忘、PAC 与旧格式兼容；不包含模型选择或桌面编辑器。

依赖与接口：宿主注入授权、提示词和估算接口；模块不反向依赖 Core 根包、Agent 或客户端。

ExistingProjects仅供宿主按已验证的搬迁路径哈希核对项目身份，返回候选中实际存在的scope，不返回原文、不修改scope，不作为模型工具开放。是否归属同一项目与冲突拒绝由Core宿主决定。

资料与状态：仅操作调用者授权的记忆根，真实用户库不直接打开验收；存在旧 Config 记忆及侧车时拒绝另建 Data 第二份库。

开发与验收：在 Core 执行 go test ./memoryservice、go vet ./memoryservice；兼容/恢复验收用合成库与原字节副本，关闭会话不能误删长期共享记忆。

兼容与交接：schema、原文来源、命名空间与事务一致性保持；桌面通过 Core 服务调用，不能恢复重复 JS 数据库实现。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
