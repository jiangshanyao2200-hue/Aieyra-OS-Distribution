# 资料初始化与离线搬迁 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[init.go](init.go)、[inventory.go](inventory.go)、[migrate.go](migrate.go)。

职责：实现 cli profile 的初始化、盘点、可接续离线迁移与取消，使用 Contracts/storage 的38类分区和历史 origin 映射。

依赖与接口：宿主先核活动 owner、旧进程和原生锁；迁移复制原件并核 SHA，不重写数据库或业务历史。

资料与状态：仅目标身份与同次迁移可接续。配置、提示词、未知文件和原目录保留；目标启用后不能以 cancel 覆盖新写入。

开发与验收：在 Core 执行 go test ./userdata、go vet ./userdata；工程外合成根验证中断、冲突、再次搬家、激活交接与移走旧源后的真实消费者恢复。

兼容与交接：初始化成功与真实资料已搬迁分别记录。历史路径由消费端映射，不通过批量改写会话正文消除路径。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
