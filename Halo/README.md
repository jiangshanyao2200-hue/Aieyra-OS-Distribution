# Halo

光圈是独立 Mod 类型，拥有图形、状态动画、渲染与配置。Theme 负责页面外观，Agent 负责身份与工作状态；切换光圈不修改名字、头像、模型、角色开关或主题。

`contract` 同时用于 Core 准入与浏览器渲染。`official` 保留原版主头像、团队、历史和设置光圈。`runtime` 负责同一文档的渲染、形态切换、隐藏暂停、减少动效和节点释放；原生浮窗只接受宿主验证过的公共选择。经典外环、状态动画和切页粒子归 `official`；自定义光圈不叠加经典外环或粒子，宿主只提供布局几何与共同 motion 策略。

资源中心导入 `SDK/examples/halo-prism`，核对、启用后点「应用光圈」。设置的身份区提供「恢复默认光圈」。独立 `Config/halo.json` 使用版本比较与原子写入；停用、更新、回退或损坏使当前投影回到默认，保留原选择以供重新核对。重新启用同一摘要可恢复；不同版本需要再次应用。

作者以 `Contracts/halo.schema.json` 为结构提示，以运行验证器为最终准入。图层支持椭圆、多边形、折线，坐标系 0–100；最多 24 层、每层 64 点。可按公开工作状态筛选，并用 2–16 个严格递增的首尾关键帧定义旋转、缩放、位移、透明度，周期 600–60000 ms。只允许声明式图形，不读取包内脚本、HTML、CSS、网络或任意 SVG。包必须声明 `halo: ^1.0.0`，无执行权限；旧宿主会报告不兼容。

官方经典包从 `Halo/official/classic` 导入。Core 以编译进宿主的完整清单摘要识别官方来源，名称、路径或导入参数不能授予官方身份；改动过的官方清单拒绝导入。导入后仍须启用和应用，停用、卸载及兼容检查沿共同注册器；作者改编时使用自己的命名空间。

修改样板后执行 `node SDK/tools/package.cjs SDK/examples/halo-prism` 更新精确文件清单。官方经典包也提供共同 Mod 清单。CLI 保留包管理与兼容报告；本版光圈渲染只声明 Desktop，Mobile 仍为契约范围。

统一入口：`official/instrument.mjs` 的 `mountHaloInstrument`/`paintHaloState` 与 `instrument.css` 共同提供完整经典主题。头像、外环、圈内思考/回应/工具信号与长等待是同一套组件；`identity.css` 只负责身份尺寸与图片，不能另造简化圈圈。`data-ring-effect` 是风格，`data-effect` 是实际工具类别，二者不可混用。角色换图只替换头像节点，不能清空 Mod/经典绘制节点；历史头像保持完整几何但不循环动画，当前招呼与工作头像按状态显示。四种经典风格都保留全套圈内信号，第三方包可用已有状态图层和关键帧定义整套几何与动画。

所有页面和原生浮窗通过同一runtime挂载；每文档共用一个有界状态节拍，离屏、隐藏、减少动效与关闭统一处理。验收必须用带PNG头像的实际会话，检查首次工作帧、状态迁移、多帧动画、身份更新不丢主题以及回退后只有一套SVG，不能以CSS变量、某个圈存在或Mod安装成功推断经典完整动画已生效。
