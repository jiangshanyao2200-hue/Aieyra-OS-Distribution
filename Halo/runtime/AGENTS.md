# 光圈运行与设置 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[desktop.mjs](desktop.mjs)、[transition.mjs](transition.mjs)、[settings.cjs](settings.cjs)。

职责：渲染同一文档的图形状态与过渡，处理设置 CAS、公开原生投影、暂停和 dispose。

依赖与接口：只消费宿主验证的公共选择、状态与 motion；经典具体图形在 official，不从身份名字推断样式。

资料与状态：隐藏/减少动效/关闭必须停或释放动画与订阅；选择失败回默认且不丢用户原选择。

开发与验收：修改后在 Client/Desktop 执行 npm run -s syntax 和 npm run -s selftest；界面变更按 docs/UI协约.md 选择受影响 AIDEBUG 场景，在源码冻结期间实看原生图。 实际跨主头像/团队/历史/设置/原生浮窗检查脉冲、轨道、涟漪与状态切换；静态截图不能验证时间行为。

兼容与交接：选择改变不重置名字、头像或任务；迟到投影不得复活用户关闭角色。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

所有surfaces必须挂载同一个完整instrument，经典回退不能仅恢复一个可能不存在的original。身份更新保留SVG，旧节点被页面重建时重新接管当前SVG，避免叠双圈。状态节拍每文档一份，只在可见工作节点需要更新时续行；风格data-ring-effect与工具data-effect严格分开。新的角色入口必须验默认经典与自定义Mod两条路径，不能只验后者。
