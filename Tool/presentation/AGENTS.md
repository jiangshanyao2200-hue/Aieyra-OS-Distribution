# 工具共同双端呈现 · 工作协约

工具投影不提供额外标签页/标签栏，窗口名称与状态归原顶栏；总览、名称选择及恢复已收起由宿主共同work-surface处理。删除标签入口须保留完整回执展开状态、焦点/滚位、总览上限与收起恢复，不得只隐藏入口导致旧窗口不可访问。

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[desktop.mjs](desktop.mjs)、[receipt.mjs](receipt.mjs)、[projection.mjs](projection.mjs)、[projection.css](projection.css)、[preview.go](text/preview.go)。

职责：把已有工具回执呈现为 cards/table、完整 JSON 与 CLI 文本；frame/value 负责安全布局和有界预览。text 子目录只读格式化。

依赖与接口：受信任宿主注入 Theme 语义槽位和操作回调；显示层不执行工具、不读取凭据、不导入 Core/客户端执行器。

资料与状态：完整事实保留，折叠/分页只影响呈现；旧代回执不能因主题或迟到刷新变成当前任务。

开发与验收：修改后在 Client/Desktop 执行 npm run -s syntax 和 npm run -s selftest；界面变更按 docs/UI协约.md 选择受影响 AIDEBUG 场景，在源码冻结期间实看原生图。 在 Tool 运行 go test ./presentation/...；长值、最后一页、详情、失败/取消/unknown和主题切换验证。

兼容与交接：新增renderer须合同、样板及文本回退；不能用简短摘要代替原始退出码、输入确认或工具日志。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

projection为只读赛博场景：Toolbox开关、项目、流程/协作、影像/视频、决策和通用事实；宿主work-surface装配窗口与终端/搜索/差异原视图。按完整调用身份保存节点，隐藏/换任务释放监听和媒体，迟到读取不得跨scope。图片读取由宿主按工具快照或经Core核准的产物注入，不接受任意路径，不为展示打开外部程序；CLI完整文本回退保持原协议。真实工具链路与合成视图验收分开记录。

隐藏时update只保留最新事实，媒体加载前后都校验当前身份。宿主恢复setVisible时同时提供最新item，避免先恢复旧回执图片再更新；未提供item的既有消费者沿用最后事实。真实最小化、隐藏期间版本变化、恢复读取路径与容器身份分别核验。

十二窗总览中，窗口内及嵌套回执滚动到底后继续交给外层grid，外层仍contain以隔离聊天和页面；聚焦与普通双窗保留原独立阅读边界。实际滚轮先核内层确已到边界，再对照窗口间隙，不能只以scrollHeight或终点截图证明可滚动。


浏览器/联系人投影由宿主注入loadProgram读取原程序事实；支持Core规范化的tool/action与旧Toolbox envelope。浏览器为真实tab只读画面，联系人为公开目录业务投影；隐藏停止单in-flight轮询、清媒体、退役读取身份，恢复只发布最新源。
