# 图片工具箱

`execute.go`负责生成/编辑参数、最高质量默认值、参考图与mask检查、一次执行的用量及图片回执、取消和不确定结果。`image.go`检查真实图片字节并读取明确传入的本地参考路径；不读取用户配置或凭据。

Core注入模型选择、调用身份、存储准备、实际供应商调用、图片保存、记账和用户可编辑的恢复文案。`API/images`独立负责HTTP/多段表单、响应及下载；依赖公共协议，不能回调工具执行器。未知付费结果不重发，已返回图片即使记账失败也先保存。

`definition.go`提供实际输入schema；`manual.txt`是随官方工具发布的完整说明。现有`Prompt/Matrix/工具说明/生图.txt`继续作为宿主可编辑覆盖，未改写旧文件；覆盖不存在时使用内置说明。提示词全部迁移和覆盖版本合并仍待统一Agent/Prompt契约。

`contract`拥有图片、批次项和结果的原有JSON结构。`presentation/desktop.mjs`提供实际进度、待核对/记账失败及后续处理事实，宿主共同工具卡渲染；共享相册/查看器继续负责图片操作。`presentation/text`提供CLI文字及完整回执，不访问执行器。

持久批次创建、锁、恢复和相册索引仍由Core现有服务提供；本目录尚不是可动态导入的Toolbox或通用Workbox运行时。质量验收仍要实际看原图，HTTP成功不等于画面合格。
