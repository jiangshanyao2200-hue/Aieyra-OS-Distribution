# 图片生成编辑工具箱 · 工作协约

遵循[根协约](../../../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[definition.go](definition.go)、[execute.go](execute.go)、[image.go](image.go)、[manual.txt](manual.txt)。

职责：拥有一次生图/编辑的规则、参考图/mask检查、schema/手册及完整图片/批次回执和视图。

依赖与接口：API/images处理HTTP，Core注入模型选择、授权、持久批次/相册/恢复，工具箱不读取私人配置。

资料与状态：付费回包与未知用量先保留，原图及引用身份不随任务换代丢失；未知副作用不可自动重试。

开发与验收：在 Tool 运行 go test ./toolbox/official/imagegen/...；实际生成→引用编辑/相册/取消按影响验证，合成HTTP与真实供应商分开记录。

兼容与交接：CLI完整回执与桌面图片事实等价；工作流编排放workbox，不把一次调用扩成隐式循环。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

公开说明与私人覆盖现经共同resources索引读取，缺覆盖使用官方默认、空覆盖保持；官方imagegen共同Mod登记已验。包内1.0.0 README的提示词“待统一”是冻结载荷的历史描述，当前归属以本协约及Tool/README为准，不直接改已编译载荷摘要。

共同完整解码包含静态WebP，像素与字节上限在解码前检查；生成原图按实际格式/尺寸/SHA登记，看图引用保留原字节和摘要。Muse图片编辑仍未验证，不能因本地可读WebP而开放远端编辑。
