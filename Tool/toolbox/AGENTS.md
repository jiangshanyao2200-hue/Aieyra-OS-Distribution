# 强能力工具箱分类 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[catalog.go](catalog.go)、[schema.go](schema.go)、[README.md](official/imagegen/README.md)。

职责：catalog/schema 统一现有能力的公开名称、摘要、手册资源键、服务归属及部分查询输入；Core 用真实调用上下文投影权限、阶段、宿主和停用恢复。目录不代表同等数量的可安装Mod，业务仍由原服务持有。当前官方独立能力为 imagegen 生成/编辑与 videogen 持久视频任务；多步骤审阅与恢复属于 workbox。

依赖与接口：toolbox同走共同兼容/手册发现与工具服务，不以名称或说明书冒充已可执行能力。

资料与状态：运行状态、模型选择、付费用量和产物由Core持久，工具箱包不附私人连接或历史。

开发与验收：在 Tool 执行 go test ./toolbox/...、go vet ./toolbox/...；改动能力同步验证输入、错误与双端呈现。

兼容与交接：升级不会把旧调用绑定到新摘要；从单工具升级工作流仍需明确workbox契约和恢复测试。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

system为发现门面，按section=settings/software/tools映射原权限和手册；不增加可安装能力，不把三个权限合成一个授权。旧名字仍可恢复/调用。公开目录不展开三个域的查询schema，打开选定分区后才加载其原手册。

第114轮：project 使用同一目录按需发现，Eyra/Cota 隐去常驻 schema，Vaya 保留直接入口；权限和原 project 执行器不变。Eyra 的 agents/community/link 直接声明，不在工具箱发现说明重复展开，旧调用仍兼容。
