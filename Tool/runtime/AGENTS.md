# 受限 JS 工具输入 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[javascript.go](javascript.go)。

职责：将已通过schema的动态工具调用转为现有 JS cell 输入，不加载任意原生 Go 或另建工具调度器。

依赖与接口：依赖 Tool/contract；Core 保存意图、授权、取消与cell执行，受限 runtime 不读取私有配置。

资料与状态：稳定调用身份与参数快照交给宿主；重开仅恢复回执，未知执行不能再生成一个新请求。

开发与验收：在 Tool 运行 go test ./runtime、go vet ./runtime，并用 Core 动态包执行测试验证真实准入/回执。

兼容与交接：改变序列化不得丢请求 ID、显式零值或回执未知字段；不能靠宽化 schema 兼容任意代码。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
