# 持久计划工具 · 工作协约

遵循[根协约](../../../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[definition.go](definition.go)、[plan.go](plan.go)、[snapshot.go](snapshot.go)、[manual.txt](manual.txt)。

职责：拥有步骤、状态、修订、依赖及输入/回执领域规则和配套视图；持久提交与任务授权归Core。

依赖与接口：Core注入计划适配器，Desktop/CLI呈现同一版本快照，不维护UI私有计划副本。

资料与状态：任务身份与revision/request_id绑定；重开读回而不把旧完成步骤再次执行。

开发与验收：在 Tool 运行 go test ./base/official/update_plan/...；Core计划提交与实际步骤/编辑/冲突/重开按受影响范围验证。

兼容与交接：保留既有计划ID、状态及用户手册覆盖；非法依赖或旧修订明确拒绝。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
