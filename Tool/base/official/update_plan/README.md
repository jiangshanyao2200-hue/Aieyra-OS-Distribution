# 持久计划工具

`contract`承接原有状态、变更、快照及错误字段；领域实现负责依赖/修订/替换/验收规则，候选更新不改原状态。`AdaptUpdate`接收宿主在请求开始时捕获的快照，不猜测版本。输入schema与内置说明归本包，工具ID仍为`update_plan`。

Core负责会话身份、权限、取消、调用去重、候选状态和回执的原子落盘及恢复；落盘失败不会提交计划。公开说明通过共同提示词索引定位本包`manual.txt`，旧路径只有被用户改写时才优先；空覆盖也保留，修改后的说明与备份不进入公共包。

`presentation`提供计划卡片、完整页、悬停、只读模型和页面默认样式。Desktop注入DOM创建函数，承接窗口、主题和滚动；CLI使用同一只读契约和文本呈现，注入终端清洗函数及宿主状态图标。呈现不能执行或完成计划。步骤全部完成与验收完成仍是不同状态。

运行`go test ./base/official/update_plan/...`；Core的回执/落盘/重开、CLI与Desktop消费者另有集成回归。安装、持久恢复与界面显示分别验证。
