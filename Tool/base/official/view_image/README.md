# 查看图片工具

`Prepare`读取并完整验证PNG/JPEG/GIF，保持单图原字节；多图按编号拼成不透明JPEG并返回来源和位置。输入字节、尺寸、累计像素和输出预算在工具内检查，透明图片合成到浅灰背景。它不访问模型、私人配置或持久资产目录。

Core负责权限与已验证模型组合、任务取消、不可变快照提交、资产授权和可选解释器。原工具ID、输入及回执字段保持；公开说明由共同提示词索引定位本目录，旧私人说明和空覆盖优先。

桌面呈现由宿主注入当前任务/Agent/代次的只读资产接口；缓存还区分Core重启，旧回调不能绘制到新作用域或隐藏视图。切换作用域、失败和取消会清除旧图。CLI提供摘要和完整原始回执，不执行工具。默认样式由本包提供，继续接受主题令牌。

运行`go test ./base/official/view_image/...`。Core快照与解释器、桌面生命周期及CLI消费者另有集成回归；安装与实际GUI按对应构建验证。
