# 读取与拼图工具 · 工作协约

遵循[根协约](../../../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[definition.go](definition.go)、[prepare.go](prepare.go)、[compose.go](compose.go)、[manual.txt](manual.txt)。

职责：拥有图片读取预备、尺寸/字节限制、拼图与完整事实/视图；Core负责不可变快照和最终授权。

依赖与接口：宿主传入可访问文件与恢复位置；相册/查看器复用共同图片服务，不另建私人资料索引。

资料与状态：路径/内容摘要/尺寸与输出回执一致，损坏或缺图保留事实；不把模型“看过”当人工实看。

开发与验收：在 Tool 运行 go test ./base/official/view_image/...；Desktop看图/引用/缩放及CLI文本按影响验证，保留失败图片原件。

兼容与交接：旧工具ID、附图身份与完整回执保持；隐藏/关闭释放视图而不删除原图。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

共同完整解码包含静态WebP，像素与字节上限在解码前检查；生成原图按实际格式/尺寸/SHA登记，看图引用保留原字节和摘要。Muse图片编辑仍未验证，不能因本地可读WebP而开放远端编辑。
