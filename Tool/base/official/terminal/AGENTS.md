# 终端工具 · 工作协约

遵循[根协约](../../../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[definition.go](definition.go)、[decode.go](decode.go)、[call.go](call.go)。

职责：拥有终端动作/旧名解码、输入契约、调用服务适配、手册及桌面/CLI回执；PTY/进程和日志仍归Core。

依赖与接口：宿主注入授权后的终端服务，Desktop注入xterm；工具视图只读回执，不另启shell。

资料与状态：退出码、输入确认、输出游标和未知字段必须保留；双PTY独立取消/输入，不跨任务继承旧代结果。

开发与验收：在 Tool 运行 go test ./base/official/terminal/...；实际验证中文输入、长日志、停止继续、双PTY和完整重开不重放。

兼容与交接：旧动作别名保留，长脚本路径不是新增请求字段；抓帧缺层与真实绘制问题分开核验。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

现行登记已完成：官方终端通过共同Mod/native准入，停用拒绝新操作、已受理PTY只读/取消与旧回执恢复保留。包内1.0.0 README的“清单接入待完成”是冻结载荷的历史描述；不能直接改它破坏宿主认可的摘要。当前使用说明以本协约及Tool/README为准。

TerminalTranscript.write返回实际加入journal的片段（尚未公告/不可展示时无返回），现有调用者可继续忽略。OperationTranscript按调用身份关联普通回执与迟到进程日志：完整前缀逐页追赶不重复，截断尾部在原日志位置由完整来源替换；游标始终用Core原始字节数，不能按中文/规范化文本估算。来源替换立即绘制，不重新逐字敲旧命令。真正相同的输出行须完整保留。

呈现载荷修改同样属于包更新：同步manifest精确摘要并递增版本，才能由宿主默认包升级把修复送到既有安装；只改摘要而保留旧版本不会自动替换旧安装。当前1.0.5包含上述来源衔接。宿主从所属模块校验后的载荷编译认可摘要，不能手填放宽清单或让导入源码获得原生权限。构建前运行extensionhost的官方工具登记、篡改拒绝及旧包升级检查。
