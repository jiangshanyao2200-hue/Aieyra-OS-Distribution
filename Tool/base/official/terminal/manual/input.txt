Continue an existing shell execution. Inspect state for timed_out/cancelled; exit_code alone does not identify why a process stopped. With no chars, wait for new output or exit; return only new output. Brief output bursts are coalesced (75 ms quiet or 250 ms maximum), without delaying process exit or cancellation. Send chars to stdin when needed. For interactive line input use chars for plain text plus press_enter:true; it adds one Enter after the unchanged text and avoids JSON escape confusion. To submit an already written line, use press_enter:true without chars. terminate=true stops this execution and its owned children. Never use exec_command again just to wait. A completed process remains readable. Calls for different sessions may run concurrently; calls touching the same session stay in order. stdout and stderr are merged in output.
Use yield_time_ms (0–30000 ms) to wait on this session. timeout_ms belongs only to exec_command and sets the process deadline at startup; it is not accepted here. An invalid parameter call does not send input or stop the session. Correct the arguments and keep the same session_id.
