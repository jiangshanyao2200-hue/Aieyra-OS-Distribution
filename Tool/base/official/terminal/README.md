# Terminal

本工具拥有统一 `terminal` 动作、旧工具名回放、严格输入契约、公开说明、服务分派、只读桌面视图和完整 CLI 回执。宿主经权限检查后注入 `Service[R]`；泛型回执保留宿主的完整结果，分派不会重建进程或序列化丢失字段。

Core 的进程服务拥有 PTY、工作目录授权、环境、并发限额、取消、持久日志、字节游标及恢复。`wait` 的时间只控制返回等待；`stop` 显式请求停止，退出回执到达前不宣称进程已退出。日志读取和旧记录恢复不能触发重新执行。长 PowerShell 脚本路径是宿主内部参数，不进入模型输入。

Desktop 注入 xterm/FitAddon、CSS URL 和打开终端的适配函数。工具视图只获得任务绑定的列表与日志读取 API，处理代次/Core 重启、迟到结果、只读输出、隐藏暂停和关闭清理。CLI 保留完整原始回执及未知字段；Mobile 尚无实现。当前原生服务随宿主构建，不能把下载的 Go 源码当成动态可执行 Mod；共同安装清单接入仍待完成。

说明通过 `Config/提示词索引.json` 映射；旧私人覆盖（包括空覆盖）优先，包内文本是经 SHA 核对的公开默认值。
