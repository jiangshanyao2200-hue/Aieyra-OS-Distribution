Edit UTF-8 text files using contextual patches. Only patch is required. Use *** Begin Patch, *** Add File: path (+lines), *** Update File: path (@@ context followed by space/context, -old, +new lines), *** Delete File: path, optional *** Move to: destination immediately after Update, and *** End Patch. Blank separator lines between file operations are accepted; blank content lines in Add File must use a + prefix. Multiple files and hunks, directories, Chinese/spaced paths, CRLF/LF and UTF-8 BOM are supported. @@ line numbers are not required. Supply enough unique context; ambiguous/stale matches reject the whole preflight with location and reread advice. Never replace a file using Add File; it refuses overwriting. \ No newline at end of file after a line is supported. Workdir defaults to the session directory; paths may be relative or absolute. All files are preflighted before writes; per-file atomic replacement plus recovery on write failure is NOT a cross-file atomic transaction. A matching call identity replays its receipt without editing again. Applied means changed on disk, not tested. After error, inspect reported files/state/recovery_path before trying a corrected patch. Use a short Chinese description.
