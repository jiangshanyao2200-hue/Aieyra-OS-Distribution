# 补丁工具 · 工作协约

遵循[根协约](../../../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[patch.go](patch.go)、[manual.txt](manual.txt)。

职责：拥有补丁解析、上下文预检、写入/恢复、输入与完整回执，contract 和 presentation 子目录共享同一事实。

依赖与接口：Core 直接调用与编排调用同一执行器，宿主注入授权根/取消/恢复目录；CLI文本视图不能导入执行器。

资料与状态：文件操作遵循工作目录/链接边界，原件和恢复回执保留；未知写入先核已保存意图。

开发与验收：在 Tool 运行 go test ./base/official/apply_patch/...；Desktop 差异视图与 CLI回执按影响验收，覆盖预检失败、原子替换和取消。

兼容与交接：输入schema/旧ID/补丁结果完整保持，不按显示摘要判断写入成功。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
