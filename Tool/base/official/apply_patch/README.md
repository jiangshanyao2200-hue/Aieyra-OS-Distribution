# 补丁工具

`manual.txt`是模型实际读取的公共说明，由Go嵌入，`PatchToolDefinition`提供同一输入schema。`contract`提供稳定输入和完整差异回执；根Go文件处理预检、唯一上下文定位、逐文件原子替换及恢复日志。

桌面使用 `presentation/desktop.mjs` 和同目录CSS显示真实差异，保持文件切换与长上下文展开；CLI使用 `presentation/text`。共享宿主注入DOM、活动状态与错误格式化能力，工具显示不依赖Desktop或CLI的内部执行器。

调用身份相同时复用原回执。多文件写入不承诺跨文件原子性；失败必须检查已写文件和恢复记录，不能把“已应用”当作测试通过。完整差异留在领域回执，模型默认只收到摘要；私人恢复资料由宿主定位，不写入工具源码目录。
