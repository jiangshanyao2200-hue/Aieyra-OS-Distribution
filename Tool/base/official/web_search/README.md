# 联网搜索工具

`Execute`校验输入并管理有界执行、取消与回执；宿主注入已授权的搜索后端。`Local`运行无模型密钥的隔离Python/DDGS后备进程，限制并发、输入输出和运行时间。来源地址原样保留，超长或不安全地址被拒绝，不截断后伪装成另一个来源。

API模块负责供应商协议和真实搜索凭据解析。Core持有已选连接快照、权限、进程平台适配与持久回执；普通回答不算联网成功，鉴权/额度/网络失败不偷偷切换后备供应商。

桌面与CLI呈现归本工具：桌面按任务、Agent、代次和Core重启分隔视图，隐藏释放动画；CLI保留完整原始回执与准确来源。说明和搜索系统指令由共同资源索引定位，旧私人说明（含空覆盖）继续优先。更新及公开打包排除编辑备份，公开说明仍须精确哈希审核。

运行`go test ./base/official/web_search/...`。宿主集成、实际GUI和安装恢复分别验证。
