# 工作流与专职 Agent · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[definition.go](definition.go)、[state.go](state.go)、[bindings.go](bindings.go)、[README.md](README.md)。

职责：定义多工具工作流、输入绑定、步骤/审阅/恢复状态与请求契约；presentation负责详情/步骤回执。Core复用工具、图片批次和AgentManager执行。

依赖与接口：Core/workbox_*负责稳定服务所有者、依赖精确摘要、实例持久化、专员端口与完成通知；不另建调度核心。

资料与状态：定义归包，实例/回执/用量归私人workflows，产物归用户工作目录；临时/保留专员独立记忆档案，不能自行批准审阅。

开发与验收：在 Tool 运行 go test ./workbox/...；Core工作流恢复与实际Node统计/写文件/图片/审阅/完整重开按影响验证。

兼容与交接：暂停停步骤边界、取消到真实执行；recover只查询已有回执，未知副作用不重发。窗口重开、通知重投与工具重放分开。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
