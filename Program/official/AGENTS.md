# 官方程序装配 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[README.md](browser/README.md)、[service.cjs](servers/service.cjs)、[service.cjs](link/service.cjs)、[service.cjs](workspace/service.cjs)。

职责：browser 管网页/身份/控制；servers 管服务器资料和领域操作；link 管设备连接、工位、收件游标与待处理通知；workspace保留原版画布、侧栏和存储，通过同一Core程序Agent及图像服务执行；各自 service 与 ui 是唯一业务实现。notes已退役，不再进入运行/发现目录；原包载荷、旧源码与用户资料保全，源码导出仍按实际交付清单处理。

依赖与接口：用户与 Agent 调用同一服务，Desktop 只注入平台能力。新增官方程序同样声明模式/权限/资料，不能复制桌面业务。

资料与状态：服务器分区和浏览器身份使用共同路径；退役便签原内容保留在原授权工作目录，源码整理不搬真实资料。

开发与验证：按实际影响选择必要检查，复用仍适用的已有结果，不默认执行 Desktop 或 AIDEBUG 全套。界面变更按 docs/UI协约.md 核对受影响的实际功能；构建与 GUI 验证串行，实际验收期间所有受测源码冻结，实看所需原生图。浏览器、服务器、Link和Workspace按改动核对实际消费者；涉及退役便签时核对拒绝执行与旧资料保全；旧路径仍被用户运行宿主引用时保留转接。

兼容与交接：官方程序随产品装配并通过共同登记；不得把宿主认可的原生载荷等同于任意第三方包。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

浏览器、服务器、Link和Workspace使用各自manifest/program.json作为包与导航来源，Core编译实际业务载荷摘要，默认登记保留用户停用/卸载；Program/runtime/native.cjs只调用宿主注入的适配器。每次新操作共同resolve并核对安装包和正在执行的Program源码，停用释放页面、浏览标签或SSH连接，私人资料保留。native声明只适用于宿主认可的精确官方版本，第三方仍走沙箱，不凭字段获得宿主权限。
本协约说明职责，不能代替实际验收结果。

原生Program业务载荷发生变化时必须提升manifest.version。共同默认包只同步到更高版本；仅重新计算文件SHA不足以升级已有安装。变更需用上一版实际包建立已启用、已停用、已卸载三种登记，验证新宿主同步、资料保留与重复重开幂等，不能仅凭全新资料场验收。
