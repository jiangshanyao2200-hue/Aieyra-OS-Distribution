# Workspace 画布 · 工作协约

遵循根协约及 Program/official 协约。src 保存 Workspace 2.0.39 的原版画布、侧栏与动效；desktop/canvas-storage.cjs 与所属子目录保存项目、素材和持久化。service.cjs 将这些能力连接到 OS 的共同 Core 程序 Agent。原安装仅供对照，不是运行依赖。

模型、四层提示词、会话、委派与工具授权来自 Core；不得启用原独立母体、模型连接、更新器或窗口启动器。画布资料由宿主注入当前安装的私人资料目录。OS 拥有顶栏，画布视觉优先保留。第114轮用户明确要求移除原版左侧侧栏及提示词、数据库、设置等多余入口；提示词、模型与工具沿用 OS 共同入口。

修改 src 后运行 npm run build；不要直接修改 dist。修改后更新 manifest 文件摘要，已交付版本的原生载荷变化须提升版本。画布保存、恢复、并发修订、撤销、引用及生成回填须核实际行为，原版功能未适配不能以静态界面代替验收。
