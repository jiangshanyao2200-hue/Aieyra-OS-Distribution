# 浏览器

`service/` 拥有网页执行、快照与过期动作检查、人机控制权、标签页、下载、浏览身份、书签与偏好。`ui/` 是实际加载的浏览器页面、导航与侧栏。两种入口使用同一个执行器和资料服务。

Desktop 注入 Electron、原生窗口呈现、界面缩放、原子写入及受控 preload 路径，负责内嵌/拆出和公共模块生命周期。程序服务不导入 Desktop，也不自行寻找用户资料；宿主提供共同路径服务解析后的浏览器资料目录。

旧 Desktop 服务入口只转接到这里；旧 HTML 供现存窗口使用，直接加载本目录脚本和样式。新的宿主加载本目录 HTML。旧路径没有独立业务实现或第二份用户资料。

浏览器目前随 OS 装配，尚不能作为普通第三方沙箱包独立导入；官方共同登记已接入。验证由 Desktop 浏览器测试、公共交付依赖检查和 AIDEBUG 浏览器场景覆盖。

本地HTML产物从Core核验后的文件卡片进入同一内嵌浏览器。`browser-artifacts.cjs`以规范目录绑定独立持久浏览身份和虚拟HTTPS来源，同目录CSS/JS/图片按实际文件读取；本场来源只访问该目录，拒绝符号链接逃逸、其它来源及写入请求。重复打开复用标签，刷新读取新字节，localStorage随该资料根保持。普通浏览器工具不能据URL取得任意本地路径授权；页面仍无Node/宿主文件接口。

左上“使用说明与 Agent 接入”可生成本次临时接入说明，复制给同机 Agent。它使用当前正在运行的浏览器及原 `execute` 队列，不另起浏览器。凭据只保存在内存，绑定当前标签组和浏览身份，仅监听随机的 `127.0.0.1` 端口；30 分钟、手动撤销或关闭最后标签后失效。生成接入不改变人机控制权；用户通过正常对话继续任务时沿既有交还流程，手动接管仍按原规则中断动作。常态状态与工具收据不发布凭据。

接口使用 `Authorization: Bearer <本次凭据>`：`GET /api/browser/v1/status` 返回授权范围及动作参数；`POST /api/browser/v1/execute` 接收 `{request_id, arguments:{action, tab_id?, ...}}`；`GET /api/browser/v1/requests/<request_id>` 回查原结果。同一编号及参数只执行一次，冲突返回 409，执行中返回 202；连接断开不自动重发，超时保留 `unknown`，先观察再决定下一步。每次授权最多保留 64 个操作回执，满后显式撤销再重新生成接入。

语义操作沿用真实 `revision/frame_id/element_id`、过期快照与 `human_control` 检查。入口不开放任意页面脚本、本地文件上传、身份或设置写入；拒绝网页 Origin、跨站请求头和非本机 Host。快照中的标签和下载同样限制在授权组，页面正文始终属于不可信数据。实际 GUI 场景为 `AIDEBUG/scenes/external-agent-access-user.cjs`；该场以独立客户端调用复制出的真实接口，剪贴板回执使用本场 renderer 夹具，不改用户系统剪贴板。

工作实例与登录身份分开：open的group_id向明确实例添加标签，new_instance:true使用同一登录身份新建实例；多实例不隐式选组。每会话独立owner，原生Navi与用户程序共享program/browser，OS会话独立。并行实例复用原runtime，动作按实例串行；可见画面预算与总标签数量分开。Agent默认控制，去掉接管按钮；真实用户输入自动使旧动作失效，新消息确认后继续并要求新快照。
