# 浏览器领域模块 · 工作协约

顶栏左侧的标签集合以浏览器浮层承载，从当前实例的完整标签列表生成，按稳定 tab_id 切换。用超过十个标签核对键盘、鼠标、当前页标记、表单与滚位；标签列表须能覆盖真实网页层。

放大镜常驻同一位置。点击和 Ctrl+L 展开地址输入，失焦、提交和 Escape 收回；地址覆盖标签区期间保留标签 DOM 和网页尺寸。按实际可用宽度显示相邻标签，少量标签平分余量；溢出时保留活动标签和全部标签入口。右上角提供收藏下拉和设置页入口。首次打开浏览器及关闭最后一个标签时访问 https://aieyra.cn/。网站与上下文菜单仍可打开链接标签。浏览器设置沿用持久偏好和原子写入。

遵循[根协约](../../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[browser-runtime.cjs](service/browser-runtime.cjs)、[browser-control.cjs](service/browser-control.cjs)、[browser-shell.html](ui/browser-shell.html)。

网页消息、权限请求和清理确认共用 OS 主题 dialog。浏览器首进、新建和关闭最后一页核对默认网址。导航栏常驻，收藏下拉和菜单打开后核对原生网页遮罩及关闭后的表单与滚位。Cookie 默认保留；菜单按身份清理，Agent 可按当前网站清理。

职责：service 拥有网页执行/语义目标、标签、快照/过期动作、人机控制、身份、书签和偏好；ui 拥有真实导航、页面与单行顶栏：地址默认折叠为放大镜，点击或 Ctrl+L 展开，可见标签随可用宽度增减及点击展开的溢出菜单，悬停不展开。聊天沿用公共透明上层，折叠后保留真实网页与滚位，不重建标签。

依赖与接口：Desktop 注入 Electron/受限 preload/原子写入、缩放及公共窗口；服务不导入 Desktop，内嵌与独立入口复用同一实例。

资料与状态：宿主注入 storage 解析的浏览器资料根，窗口关闭不清身份；截图缓存按页面/导航代次有界并拒绝迟到结果。

开发与验收：修改后在 Client/Desktop 执行 npm run -s syntax 和 npm run -s selftest；界面变更按 docs/UI协约.md 选择受影响 AIDEBUG 场景，在源码冻结期间实看原生图。 视觉/工作流测试分别覆盖控制权、实际网页/滚位、拆放重开与低对比网页；合成模型不称真实模型。

兼容与交接：Desktop 旧服务/页面只转接，禁止恢复副本；当前不是普通第三方沙箱包，官方共同登记已接入，实际验收依据对应构建的场景证据。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

manifest.json覆盖本目录实际载荷；业务、页面或协约改动后使用SDK/tools/package.cjs的pack刷新清单，再重建宿主摘要。导航来自program.json，执行适配仍由宿主显式注入。停用/卸载保留私人资料。

实例group_id与登录profile独立，多个实例时open必须明确group_id或new_instance，禁止按profile任选。原生程序、OS会话分别归属；移除接管按钮而保留实际用户输入、取消与快照代次保护。可见原生视图预算十二，总标签不设十二限制；不同实例执行并行，同实例串行。
