# 服务器领域模块 · 工作协约

遵循[根协约](../../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[service.cjs](service.cjs)、[desktop.cjs](desktop.cjs)、[app-servers.mjs](ui/app-servers.mjs)。

职责：管理服务器条目、连接/终端领域操作和用户/Agent共用页面；不在 UI 内复制 SSH 执行器。

依赖与接口：宿主注入私有资料路径、加密、SSH和原生窗口/事件，业务代码不得导入 Desktop 私有实现。

资料与状态：连接信息在原有私人服务器分区，日志/终端回执按所有者保存；不在源码、样板或地图内写凭据。

开发与验收：修改后在 Desktop 执行 npm run -s syntax 和 npm run -s selftest；界面变更按 docs/UI协约.md 选择受影响 AIDEBUG 场景，在源码冻结期间实看原生图。 资料管理、拒绝连接和窄窗可用性可离线验；远程 SSH 仅按用户实际授权另验，离线失败样例不冒称成功。

兼容与交接：旧入口转接保留现存消费者；关闭视图与停止远程执行区分，未知连接结果先查询。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

manifest.json覆盖本目录实际载荷；业务、页面或协约改动后使用SDK/tools/package.cjs的pack刷新清单，再重建宿主摘要。导航来自program.json，执行适配仍由宿主显式注入。停用/卸载保留私人资料。
