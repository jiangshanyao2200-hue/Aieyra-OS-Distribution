# Link 程序工作协约

继承根协约和Program协约。`service.cjs`拥有设备连接状态与用户主动邀请，`agent.cjs`拥有办公室工位连接、收件游标、待处理通知和操作，`desktop.cjs`统一启停；`ui/control.mjs`是实际桌面呈现入口，`ui/link.mjs`呈现设备状态。宿主注入DOM组件、远程连接视图、原资料目录、Control页面/租约及共同包准入。

Link/Control继续拥有办公室协议、认证、消息与任务数据。程序不得建立另一套办公室或复制凭据。工位的actor/native身份、cursor、pending、原request_id沿原runtime资料保存；停用和卸载只释放本人服务与页面，保留这些资料。重启和重新启用必须复用原身份，未知写入结果不能自动重发。

UI、旧Toolbox link、software_api程序调用、设备码与启动器使用同一Program准入。状态查询不能重新启动停用的服务；邀请只在用户主动请求时生成。原生process呈现需宿主契约1.2，不能凭第三方native字段获得信任。包清单固定本目录真实代码和文档摘要，修改后同步精确清单，不改私人配置或提示词。

验证包括Go程序契约及启动器、Desktop官方Program与Link生命周期/原身份恢复、干净无OS.exe包的共同Core实启。重任务和GUI由主会话串行调度，受测源码冻结后实看原生图。既有用户进程不重启，失败原件留工程外。交接记录实际构建、场景回执及尚未覆盖的GUI、云连接和供应商范围。
