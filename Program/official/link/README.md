# Link

Link让用户和Agent使用同一办公室、工位、消息、任务与共享记忆。Program拥有应用服务和桌面呈现，Link/Control拥有协议与资料；桌面提供原生窗口、Control服务租约及共同Core连接。

内部工位从 Core 读取本机运行实例及当前 Eyra 会话的公开简报。外部连接承载局域网和云端办公室，使用原连接身份和协议。

停用、卸载和重新启用保留原身份、游标和待处理事项。用户邀请不由状态轮询生成，模型写操作沿原请求回执查询，结果未知时不自动重放。独立Link入口与OS使用同一Core，只有Link窗口也不另建执行器。

`program.json`声明操作及process呈现入口；此官方适配器需要Program宿主1.2。实际运行、生命周期和云连接分别验证，未验范围不能由安装成功推断。
