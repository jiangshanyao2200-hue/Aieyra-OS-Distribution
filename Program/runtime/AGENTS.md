# 程序沙箱与端口 · 工作协约

遵循[根协约](../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[desktop.cjs](desktop.cjs)。

职责：持有通用 Program 桌面沙箱、请求端口与生命周期，复用共同模块窗口，不为每个包生成独立执行核心。

依赖与接口：宿主提供已准入包快照和受控能力；Core 通过相同服务调用，包不能 require 任意主进程模块。

资料与状态：程序存储按精确身份隔离；更新/停用取消新请求，未知执行结果查询原 request_id。

开发与验收：修改后在 Client/Desktop 执行 npm run -s syntax 和 npm run -s selftest；界面变更按 docs/UI协约.md 选择受影响 AIDEBUG 场景，在源码冻结期间实看原生图。 覆盖 CSP/导航、超时/取消、旧摘要、窗口关闭与控制权；独立沙箱样板实际运行另验。

兼容与交接：旧中心程序复用的通道保持兼容，不能以第三方包方式绕过原生文件或 SSH 权限。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

浏览器、服务器和Link使用各自manifest/program.json作为包与导航来源，Core编译实际业务载荷摘要，默认登记保留用户停用/卸载；Program/runtime/native.cjs只调用宿主注入的适配器。每次新操作共同resolve并核对安装包和正在执行的Program源码，停用释放页面、浏览标签或SSH连接，私人资料保留。native声明只适用于宿主认可的精确官方版本，第三方仍走沙箱，不凭字段获得宿主权限。
本协约说明职责，不能代替实际验收结果。

安装回执和文件监听可能重复报告同一份状态；只有官方原生程序的启用状态或摘要改变才使在途准入失效。每次快照仍核验真实载荷，并重试尚未完成的释放；真正停用、换版和关闭不能被迟到的打开请求绕过。

旧中心程序不再自行建第二个运行时。宿主注入legacyStorageRoot时按相同包ID复用原Chromium资料目录，不复制正在使用的数据库；若新旧位置均存在则拒绝并保留两份，不能擅自合并。
