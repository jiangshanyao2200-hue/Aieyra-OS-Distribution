# 人和 Agent 共用程序 · 工作协约

新增程序按[程序标准链路](../docs/程序标准链路.md)逐项接入：共同服务/工具、固定Agent和独立OS会话、共享聊天/外观/折叠、内嵌/单开、悬停预览、owner/实例隔离、背景只读投影、隐藏/恢复/退出。先登记已有/缺项和实际消费者，再复用参考实现；不能把模板当产品完成。优先复用实例以归属允许、显式身份及无并行冲突为前提；否则独立实例，不跨owner抢Navi。签名载荷内注释/文档也改变摘要，目录地图放包外，按原版本与信任流程维护。

遵循[根协约](../AGENTS.md)；当前职责与迁移边界见[工程地图](../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[definition.go](contract/definition.go)、[desktop.cjs](runtime/desktop.cjs)、[README.md](official/browser/README.md)、[README.md](README.md)。

职责：contract 定义人观察/协同/人用三种模式；runtime 管第三方沙箱与调用；official 持有浏览器、服务器、Link和Workspace的实际业务。便签已退役，旧源码已归档工程外；私人资料保留，旧调用继续拒绝。

依赖与接口：Core 提供权限/调用事实，Desktop 注入 Electron、原生文件/窗口、加密和 SSH；程序服务不反向寻找宿主私人路径。

资料与状态：程序内容和私人浏览身份由 storage 定位，停用/升级/卸载保留；运行实例锁定包版本和依赖。

开发与验证：按实际影响选择必要检查，复用仍适用的已有结果，不默认执行 Go、Desktop 或 AIDEBUG 全套。Go 检查在所属模块按受影响包串行执行，使用 GOMAXPROCS=1 GOFLAGS=-p=1，并按改动核对 gofmt；跨宿主变更按接口影响选择 scripts/check-modules.py 等检查。界面变更按 docs/UI协约.md 选择受影响的实际功能，构建与 GUI 验证串行，实际验收期间所有受测源码冻结，实看所需原生图。涉及控制权、内嵌/拆出、暂停/重开及原生关闭时核对相应真实路径；服务器仅拒绝连接样例不等于远程 SSH 通过。

兼容与交接：当前四项官方程序已接入共同登记；新 Program 与旧中心兼容转换均需真实消费者，不靠搬目录宣称完成。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。

浏览器、服务器、Link和Workspace使用各自manifest/program.json作为包与导航来源，Core编译实际业务载荷摘要，默认登记保留用户停用/卸载；Program/runtime/native.cjs只调用宿主注入的适配器。每次新操作共同resolve并核对安装包和正在执行的Program源码，停用释放页面、浏览标签或SSH连接，私人资料保留。native声明只适用于宿主认可的精确官方版本，第三方仍走沙箱，不凭字段获得宿主权限。
本协约说明职责，不能代替实际验收结果。

Workspace保留2.0.39原版画布、侧栏与动效；OS拥有顶栏，service.cjs把会话、模型、四层资料与图像批次接到共同Core。关闭和休眠先确认原画布与共享草稿落盘；失败保留页面。程序固定Agent由Agent/program目录与Core/program_agents.go登记，初始无模型，联系人可编辑并可另建独立OS会话；Eyra经共同agents目录管理与委派。

当前一环呈现与归属以docs/一环运行与投影.md为准：透明前景聊天可折叠、工具全在背景，不分聊天右栏；程序固定program_session与联系人OS sessions分开，团队可建OS会话。Brief完成退场且档案保留。浏览器按会话/实例隔离、明确group_id，Agent默认控制，无接管按钮，保留真实输入冲突与取消围栏。
