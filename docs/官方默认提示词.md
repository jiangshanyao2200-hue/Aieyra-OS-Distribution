# 官方默认提示词 v1

思考方式、自我、工作、边界四层均为外部 UTF-8 文件，独立于用户的角色私人目录。缺失的用户层采用对应默认；用户存在的空文件表示有意禁用该层。显式 system_prompt 仍按原约定覆盖组装正文。

默认层为本项目原创综合：参考 OpenAI 的项目指令分层、Claude Code 的探索/验证工作方法、Gemini CLI 的模块化提示设计、OpenCode 的持续执行与上下文接续、Aider 的既有风格及精确编辑原则。未使用泄漏或私有提示词，不复制厂商身份、工具名或操作权限。公开参考按各自许可证使用。

设置中的编辑仅写用户层；恢复默认删除本层覆盖前先保存按内容哈希命名的备份，撤销恢复支持读回备份。默认文件随签名产品更新，用户层保留。默认提示词是行为指导，不代替宿主的路径、身份、权限与事务校验。

Eyra简单任务（含编程）直接执行，复杂工作可先计划、交接和压缩再成为Cota，团队按用户要求或实际分工需要启用。Cota/Vaya保留四层可编辑内容，引用标签“角色/协定”兼容原索引；安全与边界、思考方式均在同一可编辑文件中。私人层优先于对应默认文件。

公开参考：[Codex公开执行提示词](https://github.com/openai/codex/blob/main/codex-rs/models-manager/prompt.md)，以及Anthropic官方feature-dev插件的[探索](https://github.com/anthropics/claude-plugins-official/blob/main/plugins/feature-dev/agents/code-explorer.md)、[架构](https://github.com/anthropics/claude-plugins-official/blob/main/plugins/feature-dev/agents/code-architect.md)、[评审](https://github.com/anthropics/claude-plugins-official/blob/main/plugins/feature-dev/agents/code-reviewer.md)。后者是公开插件角色文案，不是Claude Code未公开的内部系统提示词。吸收调用链调查、沿用项目结构、具体证据、定向验证与持续执行方法，按本产品的工具和身份交接协议重新编写。
