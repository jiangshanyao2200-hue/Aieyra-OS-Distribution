# Aieyra OS UI 协约

姓名旁的状态与右侧动态圆环共用 `Theme/official/default/appearance.css`：随用户状态字体/字号/颜色呈现，姓名和状态居中对齐，长状态留足环位。首页、OS会话、程序Agent、折叠和设置预览使用同一配方；空闲不残留状态环，减少动效保留静态环，不添加重复第二状态。验收须核真实圆环的连续运动和各消费者，不能从动画名称或整轮PASS推定完成。

官方默认主题的权威令牌位于 `Theme/official/default/ui-foundation.css`，旧 Desktop 路径仅作转接。主题运行时与元素目录归 Theme，光圈图形和状态动画归 Halo。下列视觉规则适用于官方主题；第三方主题仍须遵守真实状态、可读性、可访问操作、焦点、生命周期与兼容契约。

| 规则 | 协约 | 标准 |
| --- | --- | --- |
| 令牌唯一 | 同名变量只定义一处，页面不重复配方 | `--ui-text(-2/-3)`、`--ui-accent`、`--ui-error/ok/warn`、`--ui-glass`、`--ui-edge(-hi)` |
| 按钮四档 | 主要为浅底深字；设置页统一白字玻璃与亮边；次要为浅透明底与描边；轻量透明；危险使用错误色；圆形图标另设类别 | 中号高 32px，胶囊 `--ui-radius-pill` |
| 外观归类 | ID 只负责位置，尺寸、颜色和形状由类决定；唯一恢复动作至少使用次要档 | 公共按钮、滑条、标签与浮层复用共同令牌 |
| 页内浮层 | 菜单、卡片和面板使用共同玻璃材质 | `--glass-surface/filter/edge/shadow`，菜单圆角 14，面板 18 |
| 原生透明窗 | 跨 WebContents 不依赖无效的 `backdrop-filter` | alpha 材质、圆角 18，不叠加 blur |
| 覆盖层 | 透出场景，避免整页实色与重复模糊 | `--glass-veil` |
| 间距 | 一般浮层离边至少 16px，阅读宽度优先，文字保留内边距 | 间距 4/8/12/16/24/32，`--ui-pop-gap` |
| 字号与圆角 | 公开界面采用推荐字号；用户外观允许精确到两位小数 | 默认界面字号 11/12/13/14/16/18；控件 10、菜单 14、面板 18、胶囊 999、圆 50% |
| 动效 | 交互动效使用 transform/opacity，尊重减少动效；隐藏时暂停循环动画 | 160/240/360ms，`--ui-ease` |
| 图标与状态 | 左右图标复用尺寸/描边；窗口控制保持原生语义 | `--ui-icon-size/stroke`，错误/成功/警告使用语义色 |

文字与容器边框之间保留内边距。窄窗、较大字号和分栏都按实际容器宽度换行，长路径、URL、连续英文及错误正文允许在词内换行。固定单行的标题、计数和标签保留可见内边距，有省略时沿用原生提示或完整值入口。弹窗按钮能在同一按钮内换行，按钮组能另起一行。代码编辑器软换行沿用源行号。用真实的长内容和放大后的文字矩形核对两侧边距、最后一行和相邻控件。

长列表使用 `content-visibility`。顶栏空白与伸展导航保持可拖动，实际控件禁拖；原生命中与真实点击需要分别验证。

## 聊天与工作区

默认工作视图保留左侧大头像，Eyra、Cota、Vaya 按真实工作状态显示。历史内容以静态身份留档，缩小层级时仍保持清晰；角色沟通使用更小层级。姓名和光圈表达身份，不叠加字母占位；更换头像只替换 face，历史头像保留完整几何且停止循环动画。首页、私聊、群聊和招呼复用 `chat-column`、主题语义槽位和完整 Halo instrument，使用实际列宽响应布局。

同一完成正文从当前回复转入历史时，沿用共同外观的字体、行高和段落间距，不让遗留ID规则改变排版。下一次发送即使打断完成展开，也应沿原自然高度接续；独立观察须比对交接前后正文宽度与每段实际样式。

完成展开途中窗口或自然内容尺寸改变时，从当前真实高度接续新自然目标，结束前复核，避免旧目标释放后突然跳高或跳低。文字保持自然换行和原身份节点，尺寸观察随所属动画结束或打断释放；不以逐帧重排正文替代衔接。

身份交接先保证内容归属，再编排动效。旧身份在历史处收拢并停止循环，新工作身份在下方局部展开，不把旧头像跨越历史飞到新的位置。用户发送时历史平滑向上让位；连续工作时，Brief 收成上方可读的静态节点，下方接出后续工作。具体动效先由独立原型确认，再接入共用实现。动画不可造成双活动身份、旧正文闪入新轮次、清空后重新打字，或借整段淡出掩盖节点重建。

首页聊天与工作形态使用同一阅读表面和唯一布局动画；页面层不得取消其过渡、重新定格或再画跨屏光圈粒子。真正切换到其他页面时才使用页面头像过渡。连续帧验收同时观察保留节点及游离装饰层，最终长正文与工具退场需要一起核查。

产品只呈现真实内容：正常用户消息不附加“已发送”等说明；Brief 读取实际工具记录的原文，不添加编号、动画讲解或根据工具结束状态编造句子。未知接收和可操作失败继续保留必要提示。名字右侧保持原有单行真实工作状态。Brief 在工作期间继承上一段显示身份并收为静态，完成后从聊天退场；新工作段从空白开始。完整过程由 Core 原记录持有，不能将历史思考或正文作为新段的初始内容。

设置普通文字保持白色及完整不透明度，不增加设置局部背景或遮罩，保留全局背景和个人遮罩控制；选中用边线、光标和控件材质区分。禁用通过语义和轮廓表达，不能以灰化牺牲阅读。头像分组无背景框，背景图区域可保留容器；外观数值与单位对齐，无输入框外壳，仍支持滑条和直接精确输入。加粗档位必须对应字体真实能力。预览复用实际头像和聊天组件，输入条从实际头像起点对齐。自动巡检覆盖透明背景对比下界、描边、文字裁切、按钮换行和选中态，候选需结合实际原生图片判断。

统一文字颜色必须同时核对控件承托，不能把原浅底深字按钮只改成白字；普通、悬停、禁用与忙碌态使用同一可读配方。占位文字检查实际伪元素的颜色与不透明度，不以输入框的 color 代替。观察器的不可测对比必须保留原因并实看原图，不能把 null 当通过；祖先遮罩不能掩盖控件自身白底白字。滚动渐隐仅在确证全不透明的内部测量，边缘仍需看图。

所有程序使用上下分层：真实程序界面在底层持续更新，全屏透明聊天在上层；输入在展开时常驻。头像、聊天右侧按钮及当前顶栏程序图标共用折叠动作，折叠后显示当前工作头像、姓名和状态；空闲只留静态头像，再次点击展开。程序每次启动后首次打开默认折叠，本次启动内尊重该会话的展开/折叠选择；左下头像沿用外观头像尺寸，原生承载范围同步调整。首页、Coding与原生程序聊天共享阅读区/输入栏的宽度、位置和顶部留白。切到其它程序先显示其程序内容；保留节点、草稿、附件、焦点与滚位，折叠不重放任务。程序专属目录/画布结构保留，重复聊天侧栏退出。

Coding 的下层采用不透明统一主题底色，目录、编辑器和终端不叠加各自卡片边框。项目和文件可通过原生选择器或Ctrl+Shift+O/Ctrl+O打开，显式编辑后Ctrl+S保存；所选项目成为AI下次任务的实际工作目录，打开/保存/未保存是事实数据，不自动启动任务。下层采用轻量项目视野：目录、文本/差异/已观察版本、Cota/Vaya共同操作日志。默认只读，手动编辑显式开启，绑定和文件版本核对防止覆盖外部变化，编辑期间暂停跟随。上层与首页复用聊天、条件计划与报告机制。计划仅实际创建后显示，报告仅真实发布后出现；过程思考/正文/Brief在执行期间展示，结束后默认仅保留用户及最终回复，原记录可查。错误/未完成使用原状态栏的一句话，不自动展开详情或在头像上方另弹提示。

项目视野保持简约：空项目只显示必要标题和提示，保存仅手动编辑时出现，历史仅有可比较版本时出现；比较按钮可直接返回文件而不改变草稿或跟随状态。目录、文件工具栏和操作栏标题统一48px，图标控件32px；同一操作状态不重复占用两行。主题可改变内容外观，聊天遮罩、底部输入与左下折叠入口仍遵循完整工作区几何。

首页显示最近 20 轮普通聊天，用户提交立即可见，工作中的正文只属于对应输入。系统通知不进入历史；上下文压缩不替换聊天记录。姓名、等待、思考、正文和工具状态按真实投影显示。

新输入等待接收时不读取上一轮保留的思考、正文或工具尾部。工作区按Core、会话、角色和输入编号保持身份，同一活动输入内的补充及压缩不另起显示轮次。工作行完成交接保留头像、姓名与行节点；工作中的阅读区最多约头像两倍高度，内容在内部滚动；最终正文自然展开为历史，不继续限制在内部滚动框。展开使用真实几何过渡，不缩放文字，尊重正在回看的位置。名字右侧只显示单行状态，名字下方不重复添加“思考”标签。用户消息的编辑器在原消息处展开，Ctrl+回车或右下发送提交，取消及失败保留底部独立草稿；未知接收状态沿原请求编号核对。

首页背景消费真实工具回执，默认左右双窗，窄窗单列，高压总览最多12窗，支持聚焦/还原与收起。终端用轻量真实命令/日志视图，检索用来源与摘要，差异/项目用文件与片段，流程/协作用实际步骤和状态，媒体仅显示真实返回的阶段/产物，Toolbox开启、调用、关闭分别呈现。不伪造遥测、百分比、素材或完成状态；收起投影不取消任务，完整回执可继续阅读。材质复用程序遮罩/模糊，同时保留清晰的局部文字承托；结束后默认退场。外部浏览器/电脑/IDE等程序投影按独立生命周期接入，不因显示或搜索而启动外部程序。窗口缩放即时重排，不依赖新模型消息。

透明聊天位于背景工具与程序上方，可收起；工具出现、聚焦和布局变化不能挤动聊天或输入条。当前头像、姓名与状态靠近输入条，按实际内容占位，正文增长后才向上扩展，不预留未来输出的大空白。背景窗口之间优先左右并排，窄窗单列；聊天允许遮住背景内容，收起后背景仍可操作。姓名优先完整显示，右侧状态可省略。决策只由输入条向上展开，与原输入同一连续表面，不在侧栏、背景工具窗或历史再建答复框。多个问题分页填写，可返回修改选择或自定义回答，翻页只暂存，最后一次确认才统一提交。聚焦工具内的Escape先还原该视图，再由聊天处理后续折叠。

折叠态是当前工作的精简投影，支持拖动并按所属会话保存相对位置；窗口和缩放变化后保持在可用区域内。摘要从头像上方出现，最多三段实际Brief，当前思考/正文位于头像旁，不堆积完整历史；空闲后退场。沿用完整Halo与真实工作状态。拖动不能触发展开或吞掉下一次正常点击。原生浮层改变尺寸或归属前先退场，最新内容与实际视口匹配并确认绘制后再入场；同尺寸拖动直接移动原生层，不重复播放入场。快速反向、切页和隐藏须使旧确认失效，保留所属草稿与阅读位置。

OS会话与程序内对话共用消息、输入、动效与外观组件，分别保留宿主、历史、草稿与任务。团队成员可建立独立OS会话，原程序会话继续绑定自身工作。程序工具使用独立只读背景表面，不随聊天折叠矩形裁切；原生视口与当前内容就绪后再显示，隐藏释放媒体，恢复沿用原任务。浏览器按会话归属和明确实例/标签操作，Agent默认控制所属实例，没有接管按钮；真实用户直接操作自动暂停冲突动作，保留取消、代次和owner检查。

首页与各程序的招呼复用主题 live 布局；仅投影现有身份与正文槽，不制造空操作，历史消息继续使用 message 布局。

全局头像保持圆形透明，不加方形底板；主题页光圈预览卡和大预览才有主题背景块。按钮、页码圆和图标使用共同几何与实际设备像素描边，实际默认/第二主题100%与125%截图确认边缘。

## 设置与公共交互

系统信息、模型选择与侧栏加号沿顶栏区域向下无缝展开，使用同色材质和轻阴影、底部圆角；悬停不抢开菜单。消息默认至少 420px、模型选择至少 280px，空间不足再按视口收缩。快速打开、关闭和反向操作必须保留稳定命中区，避免闪烁。侧栏采用位移，保留视口、草稿和滚位。

个人设置四头像保持同等可见圈面，用户头像描边使用所选颜色且变化明显，角色使用完整光圈。换色入口不叠加背景框、不换行。预览与实际工作头像复用同一组件和实际几何。外观页不提供主题提示音、独立光圈样式或会话侧栏自定义。状态页设置名字右侧的字体、字号、加粗、间距和切换动画；思考保持统一紧凑排版，仅选择轻移浮现、柔和淡入或即时显示，预览与真实流式工作共用组件。描边与阴影颜色固定黑色，宽度随字号限制，阴影限制强度，避免文字糊成一片。头像历史双击使用可逆淡入，避免按下缩放叠加。

设置普通文字、左侧分类、标签、模型池及操作保持清晰白色；选中用承托、亮边和标记突出，未选中项也必须可读。不能依赖用户把全局遮罩调深：设置玻璃提供自身承托，检查透明与明亮背景下的实际可读性。思考内容只允许轻微色差，不使用严重灰化。字体区上排为英文字体、中文字体、字体颜色三个下拉，下排为字号、加粗、字间距等滑条。去掉重复分组小标题；加粗滑条只提供字体实际支持的范围，不制造无效参数。首页输入条左起点跟随头像和整体版式。

Eyra 头像默认120、范围100–200；用户头像默认80、范围50–150；名字默认25、范围10–50；正文默认16、范围14–20。外观滑条与数字输入保留两位小数，键盘细调不磁吸；拖动接近推荐值或末位0、5的整数时才磁吸。“加粗”统一名称。程序整体背景与展开聊天分别控制遮罩和模糊，折叠完整退出聊天遮罩。

设置卡片、提示词编辑区和粘贴文本面板使用共同玻璃令牌，避免重复外框和材质叠加。提示词禁止手动拖伸，按可用高度布局。粘贴片段展开后可编辑，Enter保存、Shift+Enter换行、Escape取消；原生撤销恢复原文，未编辑内容保留原始换行和Unicode字节，超过消息预算时保留草稿并说明原因。

设置的背景参数、请求表格、供应商分组、外观分组与提示词外层共用一套薄玻璃容器，沿主题玻璃底色降低遮挡，统一细描边、圆角和轻阴影。编辑器内部透明，不重复铺第二层材质；键盘聚焦仅增强所属外层边缘。头像与数值继续无框，整个设置页面不增加背景或遮罩。玻璃不做持续滤镜动画，亮背景下保持文字可读。

折叠聊天以实时完整Halo为中心：工作时头像旁保留姓名、右侧状态和当前思考/正文，上方仅显示最近三段真实Brief，无背景框、描边或阴影，复用共同聊天文本组件。空闲仅保留静态头像，不保留旧摘要或姓名。内容变化不得移动头像锚点，原生命中范围按实际内容收拢。展开/收起复用Halo粒子散开/聚拢，文字只淡入退场、不缩放；视口就绪、取消、反向、隐藏与减少动效共用原生命周期，自定义Halo不强叠经典粒子。原生展开需在同一已就绪视口内测量源头像和目标头像，先同步输入条真实占位，不能等待尺寸回调后才二次改位。历史读取与当次编辑器绘制完成后才进入动画，等待时完整布局可测但透明；同视口反向采用当前可见几何。验收独立检查头像坐标路径与姓名排版，不只检查视口和终点。

折叠Brief直接使用chat-column消息与真实身份小头像，小头像从共同用户头像配置派生；正文、姓名、状态与展开聊天共用同一chatLayout、外观区域和订阅，不另设talk或折叠字号。协作往来显示独立Brief，完整原文只供历史与原回执。原生转场需同时满足视口frameReady与真正portalPresented，不能在透明body中消耗动画。

主题组件预览在独立文档中运行，关闭与恢复按钮在隔离框架之外；隐藏或替换时释放媒体和资源。原生与 ARIA 控件使用真实 checked 状态。布局样例与合成状态不能代替业务、原生窗口或性能验收。

隐藏处理不依赖可能被停止的requestAnimationFrame：在可见性事件中立即暂停资源与读取，恢复后才合并布局。媒体恢复直接采用最新回执，不先载入旧图片；加载前后校验同一呈现身份。真实原生最小化、文档可见性、隐藏期间版本变化和恢复读取分别观察；反复创建/关闭核对监听、观察器、定时器与节点，不以短时资源样本代替长期泄漏检查。

工具总览中的嵌套回执滚动到边界后接续外层总览，外层隔离聊天和页面；单窗聚焦及双窗各自保留独立阅读。验证使用实际滚轮，先确定内层是否还有内容可滚，再核边界接续和窗口间隙对照；不能以内容高度大于容器高度推断滚动可用。

多窗口布局核对整个移动路径；两端留有空隙时，中途仍可能交叉。需要让位时保持当前焦点或决策连续可见，冲突窗口先原位收隐、透明换位、落位再显现，其他窗口等其收隐后移动。快速反向从当前实际几何和不透明度衔接，不能仅以终点正确或尚未入场节点透明推断整个过程平顺。

工具窗口淡入位移随实际行距收敛，保留普通版式已有的2px最小间隙，不能在10px窄行距仍固定下移12px。入场路径与布局避让共用同一位移，避免极淡的首帧边缘擦入相邻静止窗口；透明度很低也不能从几何检查中排除。

聚焦投影后的还原同时恢复阅读锚点与键盘焦点，滚动位置在布局动画测量目标前确定。总览不能因聚焦临时只有一窗就丢掉原阅读位置；尺寸变化按当前滚动边界适配，原窗口、回执与焦点释放路径保持一致。

若聚焦期间可见区域变短，还原锚点需保留原控件和焦点描边的完整可见性，原位置仍容纳时保持原位置。不能只约束scrollTop有效却把实际焦点留在裁切范围之外；按当前可见几何验收，不按工具名称猜测其位置。

减少动效不改变同一内容/视口下已经确定的聊天阅读目标。跟随正常保留当前位置时，无动效分支也应保留；只有显式重置或尺寸改变才重新适配。切换动画偏好不能使原头像、姓名和历史突然反向移位。Halo重定位的视觉溢出不作为内容增长：播放期间停止自动追尾和排队滚动帧，释放转场后再按真实内容恢复跟随，保留用户主动阅读位置。

主题契约可声明包内短 PCM WAV 资源，准入需核实际内容、时长和对齐；SDK 导出保留审核过的图片、字体与声音。这不表示外观页提供声音设置或所有表面均有播放器。

预览复用完整角色光圈和真实头像几何。加粗范围取所选内置字体的真实轴交集；系统及回退字体只提供常规与加粗。状态不提供行高设置，字体颜色可保存并应用；状态保持完整颜色和不透明度，切换动画不做灰化或淡到难以辨认。所有数字输入不画下划线。个人背景预览在上、参数在下；弹窗动作使用共同按钮，忙碌文案保持单行。添加模型只保存配置，文字响应测试由单独操作触发，不把尚未测试的能力标记为成功。提示词只改正文时不受无关个人资料版本影响，显式保存使用最新正文版本并保留备份；系统默认内容可直接保存，不制造无意义的私人覆盖。个人身份更新保留消息中的编辑器、草稿、选区及发送请求身份。

## 检查与实际观察

运行 `python -B -X utf8 scripts/ui-contract/check.py`，静态基线由 `Client/Desktop/test/ui-contract.test.cjs` 持有，只降不升；静态数量不代表视觉质量。相关 AIDEBUG 场景见[操作手册](AIDEBUG.md)。

界面修改须在同一受测构建中核对默认/可选主题、正式缩放、窄窗、滚动、键盘、隐藏恢复和正常重开；查看原生图及连续帧并登记观察。CSS 变量、DOM 存在或单张静态图不能证明实际布局、可读性和动画正确。帧时间、长任务、内存与进程 I/O 分开记录，rAF 不等于物理屏幕帧率。

决策既有背景只读投影，也从原聊天输入条向上展开问题、选项与依据。选项不自动提交，用户可直接在唯一主输入中回答，通过确认按钮或Ctrl+Enter提交。普通聊天草稿、附件、粘贴和选区保留，每个问题有独立回答草稿；稍后或切页不隐式采用推荐。新问题不打断输入法或正在写的普通草稿。提交绑定原问题/代次/版本，未知回执保留相同请求身份，迟到结果不能覆盖新问题。

决策展开与收起同时连续让出实际布局空间，不能用内容淡入替代聊天视口的过渡。正文不缩放，反向从当前可见几何接续；退场即时停止旧问题交互，普通草稿恢复与提交不等待动效。减少动效、隐藏及原生尺寸变化释放当前过渡，重复快照保留节点和已在进行的通道。

普通草稿与问题回答即使初始等高，面板让位期间也保留原输入外层的固定高度；自然输入增长沿原尺寸观察与结束检查共同续接。不能等输入已经同步跳高后才启动平滑，也不能为让位逐帧改变textarea自然尺寸。

连续布局的测量先完成全部几何和计算样式读取，再写当前结果；动态输入高度、聊天留位与输入轴线只放在实际消费的表面，专用变量不继承到正文与工具子树，避免写body触发整页继承样式和无关观察器。相同值不重写，隐藏元件和未启用的旧浮动布局不读几何。性能诊断分别归属受测renderer，嵌套timeline耗时不相加；最终开销另用无CPU/timeline、无截图和逐帧几何的有界计时核对。

页面专用样式以所属组件已有的显示生命周期为准。嵌入报告不使用全body的后代显隐选择器持续观察聊天和工具DOM；阅读状态只在实际显隐变化时发布，关闭清理。动态尺寸发布前先核实际消费者，无消费者的全局逐帧变量直接退出；性能修复需保留相同诊断模式下的原始失效链及实际界面复验。

聚焦还原沿用同一仍连接的控件；窗口关闭、回执移除、换任务或改选时释放旧焦点引用。局部回收检查须保留公共组件句柄并使用独立强/弱对照和真实renderer受控GC，区分DOM移除与对象回收，不推定完整应用长期无泄漏。

工具投影聚焦、还原和改选沿用原窗口，以真实尺寸和位移连续过渡，不缩放文字或按钮。打断先读取当前几何，反向从当前状态接续；隐藏/删除/关闭释放动画，减少动效直接提交布局。实测中间宽度、文字变换和快速反向，终点截图不能证明没有跳切。

新工具到达时也沿用同一让位过程，普通内容更新不重启动画。旧窗口先让出空间，新窗口再显现，避免半透明内容、标题或描边叠在一起；暂不可见的新控件不参与命中与键盘访问，动画结束或取消及时释放。呈现顺序不阻塞实际工具执行与回执读取。连续帧需检查窗口之间的关系，包括新工具入场、聚焦还原和快速反向，不能仅凭各窗口本身的几何连续认定视觉正确。

## 阅读内容与浮动入口

浮动圆、按钮和光圈的安全空间覆盖正文与页头，也覆盖隔离HTML；不能只让标题避让而让正文末字被压住。共用原布局提供的空间，入口缺席时释放额外留位，主题和窗口调整不重载正文、不清除读位。缩略拼图可能漏掉单字遮挡，必要时打开实际原生原图，再以裁切后的字形范围定位；早期接受发现有误时保留历史并修正当前结论。
