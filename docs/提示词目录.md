# 提示词目录与维护协约

公共提示词按所有者归位，Config/提示词索引.json 保留稳定逻辑名称；逻辑名中的 Matrix、子代、潜意识不是另一个磁盘目录或启用角色的指令。

| 所有者 | 权威位置与职责 |
| --- | --- |
| Eyra | Agent/official/Eyra/prompts：contracts 执行协定；default 四层公共默认；instructions 运行引导；tools 宿主能力使用指令；connection 连接检测；greetings 问候；delegation 委派模板 |
| Eyra 上下文 | Agent/official/Eyra/context/prompts；legacy 保存旧潜意识流程仍需兼容的文案，不启用退役角色 |
| Vaya / Cota | 各自 Agent/official/角色/prompts |
| 独立工具 | Tool/base/official 与 Tool/toolbox/official 对应包的 manual；工具协议和实现由 Tool 维护，Eyra/tools 只说明角色如何使用宿主能力 |
| 私人四层 | 已归位目录为 Data/Agents/Eyra/prompts，统一资料根下按 agents 分区映射到 Agents/instances/Eyra/prompts；空文件、原始换行、备份和恢复记录均保留，绝不进入官方包 |

私人路径优先级：显式 prompt_dir；当前资料根中已存在的角色目录；兼容旧 Prompt/Matrix。离线迁移须先正常退出写者，逐文件校验内容摘要并保留备份。只读装载不自动移动或创建目录，未迁移用户仍可正常使用旧布局。资料离线迁移沿共同 agents 分区复制和重定位。

公共说明经 Core/prompt_locations.go 与 Client/Desktop/src/resources.cjs 热读同一索引；旧逻辑路径中的用户修改按 legacy_sha256 保留为覆盖。不能直接以文件名拼接旧 Prompt 位置。统一资料根下，运行说明编辑器经索引读取官方资源，编辑写入 Overrides/Agent/official/<角色>/prompts 或 Overrides/Tool/<所属路径>；既有 Overrides/Prompt 覆盖继续读取，首次修改转到所属模块路径并保留旧文件。旧布局也写入其 Data/Overrides/<模块所属路径>，双端优先读取，离线迁移映射到统一 Overrides；编辑不会改官方包。私人四层编辑器只写已解析的个人四层；恢复默认和撤销继续使用版本检查及内容摘要备份。

维护公共文案须更新索引、scripts/public-privacy-policy.json 的逐文件摘要及所属 manifest。变更包载荷后用 SDK/tools/package.cjs 更新清单，再验证官方 Agent 准入、Core 与 Desktop 提示词读取/编辑/默认恢复、公共导出。禁止把私人内容登记为公共白名单；禁止为了整理复制同一份权威提示词或用目录链接隐藏重复。

职责与继承：角色子树遵循 [官方角色协约](../Agent/official/AGENTS.md)，工具遵循各自协约；本页承接已退役根 Prompt 的维护说明。 [工程地图](工程地图.md)提供模块导航。
