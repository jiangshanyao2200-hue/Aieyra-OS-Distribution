# 客户端与共同核心

| 位置 | 当前实现与依赖 |
| --- | --- |
| `Client/CLI/host` | 现有CLI命令、交互会话、配置与Mod入口；调用共同Core及公共协议 |
| `Client/CLI/terminal`、`mdrender` | 终端输入、排版和状态呈现；依赖公共协议、显示库及Tool只读文本回执，不导入执行宿主或工具执行器 |
| `Core/cmd/aieyra-cli` | 兼容启动入口，转交Client/CLI；现有OS终端回退与配置入口也使用同一实现 |
| `Core`、`Core/host` | 执行、Workspace、设置、会话、模型worker与宿主服务；Core根包不导入Client |
| `Client/Desktop/host`、`Client/Desktop/src`、`Client/Desktop/ui` | 唯一桌面源码；根Desktop仅保留精确清单固定的兼容资源，旧实现退役前核对运行消费者 |
| `Client/Mobile` | 手机端契约与目录预留；未开发App |
| `Contracts/product-layout.json` | 交付库存包含Client模块及三个客户端目录；构建自动发现并检查独立Go模块 |

CLI实际实现已从Core迁出，原命令入口仅转交，不保留第二份客户端。Client调用Core，Core/cmd作为组合入口调用Client；两个go.mod的本地引用不代表包循环。公共边界由 `scripts/check-modules.py` 检查，包括Windows/Linux/Android的CLI依赖，以及终端呈现不反向依赖执行器。

客户端共用任务、取消、会话、记忆、工具和包服务，不复制业务状态。Android命令行依赖通过不等于手机App验收；Desktop源码归位不等于旧用户进程已重新加载。实际入口与各平台运行分别验证。

Control/app/mobile是Control已有Android客户端，不是这里规划的OS手机App。各端协约与机读目录见[工程地图](../工程地图.md)；手机契约、CLI跨端管理和真实设备通信分别验收。

跨端管理接点在Client/CLI/host/remote_service.go：CLI以本人私有discovery连接已有Core，context/contacts/workflows/agents复用桌面相同RPC及source、generation、版本、权限和清理回执；不另开执行器。旧普通会话命令仍退役，context仅选桌面主会话。验证同Core双向读写、冲突拒绝、原文与产物保留及完整重开，不从单个RPC成功推断整条链通过。

独立Link入口与OS入口共同调用Core/host/desktop_bootstrap.go处理worker、更新维护与配置，再进入RunWorkspace。无OS.exe发行包仍拥有相同Core；同资料已有宿主时沿运行时锁复用。纯模块启动推迟自动问候/历史摘要/办公室唤醒；显式用户工作恢复执行。Client/Desktop/host/modules/main.cjs只转交共同启动器，旧独立业务宿主已核消费者后归档工程外。独立包、已有OS复用和多次拆放须分别实测。

公开开发文档清单统一在`Contracts/development-documents.json`，与`product-layout.json`共同供Python打包、Desktop更新器和Go更新helper消费。公开文档精确准入，Agent/context/history与Link/cloud的声明源码可更新；其他私有历史、云端资料和数据库仍禁止。完整ZIP验证应覆盖本地合并、提交、启动异常回滚和旧程序重开。

共同成员投影：Core/conversation_groups.go与conversation_link.go提供真实状态、updated及脱敏error；work-selection管理显示准入/优先级/错误文案，work-participants复用于首页、私聊、群聊。更新服务独占当前通知连接并在登录/关闭边界取消异步操作；不是每个设置页面各建一份更新器。分别记录状态投影和异步生命周期回归。


一环的原汉堡、OS会话与三程序聊天由原Desktop入口恢复，复用chat-column、createDecisionSession与work-surface；独立身份/草稿/任务保持。职责与真实源见[一环运行与投影](../一环运行与投影.md)。
