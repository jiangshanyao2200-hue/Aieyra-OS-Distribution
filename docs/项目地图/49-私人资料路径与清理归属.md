# 私人资料路径与清理归属

`Contracts/storage/areas.json` 是现有资料分区的共同声明。Go 与桌面实际解析同一文件；`Core.PrivatePaths`、`Core/platform.ResolveLayout`、`Client/Desktop/src/paths.cjs` 提供入口。`workspace.paths` 返回区域、路径、所有者和清理策略。初始化、迁移和运行恢复分别验证。

| 区域 | 实际所有者及生命周期 |
| --- | --- |
| sessions / context | Session 服务；前者兼容独立档案，后者保存主会话目录和档案版本。Context 提供者的状态按命名空间保存，不能拥有整个目录 |
| conversations | 联系人及独立会话；删除按逐项回执重试，联系人提示词和头像单独保留 |
| memory | Memory 服务；长期共享记忆、完整原文投影、PAC和转录发件箱。关闭会话不等于遗忘共享记忆 |
| runtime/attachments | 附件快照和草稿/发送引用；只有核对来源及全部引用后才能回收 |
| gallery / generated-images | 图片库与图片服务；关工具和换主题保留资产及结果，未知生成结果不自动重发 |
| reports / logs | 诊断所有者按保留策略管理，不作为唯一聊天原文或工具回执 |
| runtime / matrix | 宿主运行态与Agent任务资料；按实例确认写者释放和任务结果。runtime里的附件有独立生命周期，不能清空整个父目录 |
| Programs | 程序私有资料，包停用、升级或卸载时保留 |
| Packages / Modules | 包服务管理不可变载荷、依赖锁及用户模块；官方更新不得覆盖用户作者资料 |

标准Config文件旁使用既有Data根，外置显式配置继续使用相邻资料根。解析不会创建目录、访问SQLite或移动资料；配置、私人提示词和用户工作目录保持各自入口。契约映射不是文件权限或递归删除授权，所有者仍须执行引用、租约、版本和回执校验。

路径声明本身不搬资料。当前Core/userdata已有统一根初始化、盘点、离线迁移/恢复/取消，命令和约束见[storage说明](../../Contracts/storage/README.md)。真实目录整合须先释放写者、保全原件再逐文件校验并交接；旧Config记忆及侧车仍明确阻止创建第二份Data记忆库。全类型Session共同目录和最终故障验收不能仅以路径声明或搬迁通过代替。


共同声明还覆盖：旧workspace/CLI档案、项目索引、批次、站点、浏览器/预览/桌面profile、截图、配置修订、旧应用/资源/社区/更新、Link、便签/服务器和桌面状态均经实际消费者解析。所有旧位置保持；配置专属目录缓存及Config旁配置仍保留原入口。附件清理补入持久Agent/Workbox/批次/旧CLI/Program/图片引用，损坏或未释放写锁时保留。用户产物与工程索引使用共同私人根排除，含配置专属缓存。

默认工作目录会探测可写性，安装旁不可写时退到当前用户的AieyraOS/工作目录；AIEYRA_WORKDIR显式选择失败会报错。路径映射、统一根迁移与恢复须分别验证，不能用单次路径检查代替运行验收。

2026-11-06当前边界：37区域经Go/JS共同Bind固定配置所有者；只有有效资料根声明使用profile_relative布局，既有配置沿旧位置。迁移复制原件和未知文件、逐文件核SHA，不改写数据库/原文；历史绝对引用在实际消费时解析，可接续、再次搬家和取消未启用目标。目标启用后不覆盖新写入；活动owner/旧进程/锁、链接、目标冲突和坏回执均拒绝。

实际主工程用工程外合成资料验证主会话、联系人、普通任务、标准Agent和Workbox在移走旧源后恢复身份/历史/产物且不重放，九份合成原件SHA保持。未迁移真实用户资料；全类型Session共同目录、逐项清理回执/重试和T10两次迁移记忆身份回归已验。真实路径、工作协约和未完成项见[工程地图](../工程地图.md)。
