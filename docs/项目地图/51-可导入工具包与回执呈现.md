# 可导入工具包与回执呈现

工具包通过共同Core登记、执行与呈现，安装与实际运行分别验证。

| 职责 | 实际所有者与消费者 |
| --- | --- |
| 包身份、兼容、导入、权限、更新/回退 | Core/modules共同登记；extensionhost校验tool/toolbox完整载荷，不另建工具登记库 |
| 定义、schema、完整手册、两端视图校验 | Tool/contract/package.go；Core/tool_packages.go发现与解析 |
| JS输入与实现封装 | Tool/runtime；Core/toolbox.go装配现有受限cell执行器，权限与取消仍归宿主 |
| 桌面与CLI回执 | Tool/presentation；Client/Desktop/ui/tool-digest.mjs与Client/CLI/terminal实际消费 |
| 持久活动与异步输出 | Core/tool_package_preview.go与matrix_activity.go保存呈现、合并wait、保留终态输出 |
| 作者样板 | SDK/examples/tool-statistics真实计算；toolbox-report实际创建JSON报告 |

身份为 `mod:<包ID>@<完整64位摘要>`。新调用须匹配已启用版本；更新/停用不能把旧调用改绑到新代码。调用接纳点是载荷读取后再次核对的登记快照，执行期间不持有登记锁。已接纳cell沿原身份查询。包调用不向默认角色开放任意exec；子Agent必须明确获授完整版本及所需内层能力。

缺手册、实现、两端视图、未知renderer或权限不匹配时拒绝导入。桌面cards/table只将实际回执值作为文本展示，不执行包内HTML/JS。表格附加输出可展开，当前原始回执保留；大活动预览明确截断，完整历史另存。CLI保留完整JSON投影，正式CLI开关不变。

Windows登记读取采用privatefile.OpenSnapshot，提交采用WriteSnapshot；读取者持有前一版本，新读取者看到原子提交后的版本。普通privatefile.Write语义保持。市场列表只接纳当前请求结果，每张卡片绑定绘制时修订号；迟到请求不得改变操作前置版本。

验收场景为 `tool-packages-user --display --scale 1 --exe <安装入口>`：真实导入/授权、手册、计算/写文件、默认及第二主题、更新拒绝旧版本、回退、停用、重开与连续十二轮启停。供应商是本地合成夹具，外部模型调用0；不能据此宣称真实模型体验已验。失败原件与修正后场次分别保留。
