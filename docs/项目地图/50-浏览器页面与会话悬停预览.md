# 浏览器页面与会话悬停预览

浏览器真实页面选择在`Program/official/browser/service/browser-runtime.cjs.previewTarget`，包括WebContents、视口就绪与页面/导航身份；实际页面在同模块ui。`Client/Desktop/src/browser-runtime.cjs`仅为兼容转接。Desktop注入Electron/原生呈现和公共窗口；`Client/Desktop/host/browser.cjs`在收起前恢复正常边界、等有效视口并捕获页面，再隐藏窗口。`Client/Desktop/host/desk-park.cjs`管理有界截图、同源缓存、迟到结果和恢复取消；隐藏页面只读缓存，换页/来源丢失不可复用旧图。`Client/Desktop/ui/module-preview.mjs`负责顶栏程序悬停预览并标记“上次画面”（桌面模式已移除，停放不再启用），失效时展示不可用。`Client/Desktop/host/main.cjs`负责放回后的浏览器导航。

会话行由`ui/contacts.mjs`接入`ui/session-preview.mjs`，450ms悬停或focus后只读已有snapshot，采用现有原生tip窗口。最近四条、每条120字、最终有界；主会话过滤内部过程，待清理会话只显示回执。1.5秒更新，离开/失焦/页面隐藏等取消，epoch拒绝迟到响应。不创建新会话窗口或调用模型。

验证入口包括 `Client/Desktop/test/desk-park.test.cjs`、`session-preview.test.cjs`、`browser-host.test.cjs` 以及 AIDEBUG 的 `content-preview-user` 和 `browser-visual-user`。在完整工程中按[操作手册](../AIDEBUG.md)运行；确认截图来自真实可见页面，观察延迟预览、快速反向、隐藏恢复、缓存失效和连续窗口几何。群聊、外部网页和各平台覆盖分别记录。

`desk-park` 按 key/窗口管理关闭监听器，可取消过渡并复原，缓存只读不递增捕获序号。浏览器收起前与恢复共用 `module-window.restoreModuleBounds`，避免原生边框取整累积。停放入口的退役不等于顶栏预览和缓存生命周期可以删除，删除前须核消费者。
