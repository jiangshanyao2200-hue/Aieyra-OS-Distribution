# 长期协作开发

本规范面向人和AI持续维护同一个工程。新要求先记录原文、适用范围、完成判据与执行表，再执行已经授权的工作；不中断工作等待重复授权。稳定规则写最近AGENTS，任务状态写当前任务文档，历史与证据独立保留。任务记录、用户偏好及原话不进入公开源码或包。

可运行入口见[AI开发工具](AI开发工具.md)。用 context 查同一个实现，使用 checkpoint/resume 保留接续，通过日常桌面窗口核对实际结果。

## 最小阅读路径与抗压缩

恢复时只按“根AGENTS → 当前任务/接续点 → 对应代码目录CODEMAP → 最近AGENTS → 相关链”展开。不要把全部历史日志、全量地图或所有模块一次读进上下文。新的用户补充先追加原文和执行表，保留原任务及已完成项；只有明确取消或冲突才替换目标。

当前任务文档至少保留：原文、目标、已做/未做、当前工作文件、下一条具体动作、失败原件、实际命令及退出码、构建身份、证据路径、本人活动进程/请求、预算和禁止事项。压缩前、切阶段、发现重要失败、结束一轮时更新；活动进程必须记录PID、启动时间、工具session与所属证据，避免压缩后丢失观察或清理责任。

交接写事实，不只写计划。检查通过、产品实现、实际运行、原生可见、人工接受和真实模型分别记录；未完成明确写未完成。旧构建通过不能移到新构建，失败不能覆盖，文档变化也不能冒充运行代码变化。

## 注释链和目录地图

维护入口是[code-chains.json](../Contracts/code-chains.json)的人工核对链、[工程地图](工程地图.json)的模块所有者，以及[code-atlas.py](../scripts/code-atlas.py)的源码索引。代码顶部AI-CHAIN指向就近CODEMAP；每张目录地图列文件、区域候选、静态导入、消费者、所属链、边界和验证场景。签名/精确兼容/生成载荷采用包外地图，不插注释或MD改变原字节。

```text
python -B scripts/code-atlas.py show Client/Desktop/ui/chat-column.mjs
python -B scripts/code-atlas.py chain chat
python -B scripts/code-atlas.py recipe
python -B scripts/code-atlas.py refresh
python -B scripts/code-atlas.py check
```

show只加载索引并核当前文件及链契约；check核全图。新增/删除/移动文件、改符号或依赖后refresh，交付前check；生成内容与正文分离，重复生成不能改变正文、编译指令、编码头、许可证和签名载荷。生成工具在写入前检查源码未被并发改动，以临时文件原子替换，残留失败文件保留待核。

索引中的Python顶层声明来自AST；其他符号及字面量导入是词法候选，不能推断完整调用图。Go同包、IPC、事件注册、主题/CSS、模板、动态import及原生回调须沿人工链和实际消费者补查。修改同一功能时维护其共享所有者及所有消费者，不能把“未找到静态导入”当成无影响。

有效的区域注释回答“此段由谁调用、改变什么状态、依赖什么身份/代次、谁拥有取消与释放、哪些消费者一起变、如何证明”。保留已有解释原因和边界的注释，不逐行复述语法，不填未经核实的因果。生成区域目录定位源码，人工注释解释不能从语法得到的约束；两者互补。图是可失效导航，不是自动证明。

## 城市化与可复用结构

| 环 | 职责 | 复用方式 |
| --- | --- | --- |
| 市中心 | 契约、授权、执行、会话/持久事实及数据边界 | 同一Core和Contracts；不在界面复制执行/权限逻辑 |
| 一环 | 共同聊天、输入/决策、主题、动效、工具视图、程序共同服务 | 唯一实现、显式参数与生命周期，多场景消费 |
| 二环 | 首页、OS会话、程序宿主和平台装配 | 组合一环，保持scope/owner/实例独立 |
| 三环 | 具体程序/工具、作者样例和开发验收 | 按共同标准扩展，能力缺项明确登记 |

环号是职责阅读层次，不是新目录树，也不替代现有依赖规则。按职责让一个能力尽量集中在一个文件；共享契约、独立数据生命周期或平台边界需要拆开时就拆开，避免为“单文件”合并不同所有者或形成巨型文件。先搜索已有实现/消费者和链，再判断新增还是扩展；不以复制聊天/按钮/标签页/CSS快捷完成新入口。

按钮、菜单、玻璃材质、字体/姓名/状态/头像、动效时间线等属于一环；整体聊天、决策、背景舞台、程序Agent也是可复用大模块。复用包含保存订阅、语义消息、权限、取消、错误、隐藏、释放和恢复，不只是外观。程序接入按[程序标准链路](程序标准链路.md)。

## 真实使用与修复闭环

从日常桌面快捷方式进入产品，沿原生入口执行实际操作。实看结果、原消息和代次与运行构建一起记录到当前任务笔记。后台读取同一进程的运行状态。依据真实失败直接修复主工程，再按原动作在日常窗口复验。[AIDEBUG 操作手册](AIDEBUG.md)

## 精细质量与成长记录

把一像素对齐要求变成指定缩放、字号、DPI和实际几何的可测判据；分别记录CSS像素、设备像素和取整误差。按钮同时验命中、悬停/键盘唯一活动项、焦点、禁用、错误、窄窗与辅助名称。动画核开始/中途/终态、快速反向、隐藏、减少动效、资源释放；性能诊断与无诊断计时分开，保留原始间隔/长任务及测量范围。审美仍须实际看图，不能只查CSS字符串或DOM节点。

每条可复用经验保留“触发 → 原因 → 共同修复 → 验证/证据 → 适用边界”。稳定经验归最近AGENTS；目录地图从代码生成，避免手工同步重复目录。任务结论保留在任务文档；根AGENTS只放索引、稳定规则与当前入口，历史另存，防止越来越长而淹没当前约定。未来编程Agent复用这些公开开发工具和契约；不得因此读取私人任务原文、接管本次开发进程或获得额外执行权限。
