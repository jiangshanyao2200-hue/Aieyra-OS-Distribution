# 规范与工程导航 · 工作协约

遵循[根协约](../AGENTS.md)，从[开发指南](开发指南.md)、[工程地图](工程地图.md)和[专题地图](项目地图/README.md)查找职责。本协约覆盖没有更近协约的自有子目录；测试、资产和第三方依赖不因此成为独立执行模块。

本目录维护架构、开发、UI、提示词资源、资料归属和测试方法。模块路径、调用者、接口与兼容边界以源码和消费者核对，不以目录存在代替实现或验收。

公开文档逐文件列于 `Contracts/development-documents.json`，根导航由 PUBLIC 模板生成。用户原话、私人进度、协作身份、运维信息和完整证据只保存在私有文档或工程外，不进入公开白名单。签名包载荷不因文档整理而绕过完整性校验。

新增或移动入口时同步对应规范、模块协约、机器地图和文档清单，先查消费者再归档。修改后检查相对链接、地图路径、导出范围与隐私；不为文档改动重跑无关产品构建或 GUI。测试结论须标明实际范围，失败原件保留，历史记录不能充当当前验收。
