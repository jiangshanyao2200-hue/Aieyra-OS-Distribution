# 当前阶段入口

唯一阶段开关在 `Config/运行参数.json`，Core 与 Desktop 读取同一资源。

| 开关 | 当前值 | 作用 |
| --- | --- | --- |
| os_first_ring | true | 主页、设置、浏览器、联系人、Coding、汉堡及 OS 会话；Coding 沿用 Core 受管项目及 Cota/Vaya 会话 |
| toolbox | true | 共同工具箱入口，实际能力仍受角色/会话授权 |
| team_collaboration | true | 共同协作执行协议；不代表所有程序菜单开放 |
| link_situation | false | 不自动加入远端 Link，不显示对应入口 |
| cli | false | 独立 CLI 阶段入口关闭 |

服务器、工作区、资源中心和其他城市应用入口继续隐藏。Coding 的顶栏入口打开原编程工作台，再次点击可收放聊天层。后续程序启用沿原服务逐项适配。具体调用关系见[一环运行与投影](一环运行与投影.md)。
