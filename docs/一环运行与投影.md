# 一环运行与程序投影

共同工具可视化不提供标签页/标签栏。各窗口顶栏保留名称、状态、聚焦与收起；总览内点名称选择窗口，已收起内容沿共同恢复动作找回，完整回执与阅读状态保留。没有额外操作时公共操作栏隐藏。

Core Link的活动成员与归档作者分别投影，归档只释放席位，消息页内旧Brief继续通过同一作者解析保留姓名、角色、光圈及头像。归档作者不参与工作席位或执行发现，头像读取仍限当前协作范围，重开不恢复派工。

OS 核心拥有持久会话、AgentManager、授权、模型请求、工具执行和完整回执。浏览器、设置与联系人沿用原 Program 与业务服务；Navi、Sera、Mira 是各程序独立的持久 Agent。默认显式跟随 Eyra 的模型，也可各自选模；共享模型不共享历史、草稿、任务或权限。

`Config/运行参数.json` 的 `release_stage.os_first_ring` 恢复原汉堡会话、浏览器和联系人入口。Link 自动加入继续由 `link_situation` 独立控制；未开放的城市程序不随一环显示。缺少一环开关的旧包按 false 处理。阶段状态见[清单](阶段性隐藏功能清单.md)。

## 同一聊天链路

个人外观的 chatLayout 与文字区域订阅同时用于首页、私聊、群聊、程序聊天和原生折叠投影。会话抽屉、其展开子会话及联系人页会话列也消费共同姓名和按实际作者选择的正文样式；列表与 Brief 的小头像从同一用户头像尺寸按比例派生。折叠仅缩减显示轮数，不建立另一套字号、身份或资料。协作实时只显示作者 Brief，沟通原文由原历史与回执读取。

主页、普通 OS 私聊与程序 Agent 使用共同 chat-column、外观版式、工具 work-surface 和输入决策。程序历史由原 agent-dock/chat_page 分页。联系人sessions只列OS会话，program_session明确标出原程序固定会话；program_open按原创建请求program/<id>恢复，不能用最近会话代替。团队角色允许新建OS会话，提示词定义共用，历史、草稿、工作归属独立。最终正文自然展开，工作阅读可有界；无虚假“已发送”标签。人工问题只从唯一输入条上方展开，多问分页暂存、回改，末页统一确认，实际仍按原逐问题 RPC 与幂等回执提交。

私聊和程序会话由共同 `ConversationPresentation` 消费原 `WorkTranscript` 与 Brief 分段。旧工作身份原位收成真实 Brief，下方新身份展开；最终持久回复保留工作行的显示编号、头像与姓名节点。`agent-dock` 的分页归并仍以原快照编号去重，布局与滚动交给和主页相同的 `createChatLayoutMotion`，用户回看时保留阅读位置。工具属于背景工作舞台，前景聊天透明且可折叠；工具窗口在背景内部并排，不改聊天的宽度或位置。工作头像仅按实际内容占位，短等待靠输入条，正文增长才向上延展；完成正文自然展开。Brief仅在当前工作期间显示，完成后退场，原档案仍保留。

OS会话在自己的文档中承载背景舞台与共同layered-chat。程序聊天的原生层保持透明，背后保留原程序；其他工具由同一work-surface在独立只读原生背景中呈现，聊天折叠不会裁掉它。Navi自身浏览器不再自投影一张重复卡片。个人聊天遮罩与程序工具材质分别沿用既有配置。

首页挂载页与独立首页时才显示的 OS 容器共用原工作区位移协议。宿主仅接受当前原生页面所有者的 `workspaceShift`，隐藏容器不能在 resize 或最小化时清掉可见页的侧栏避让；拆出/放回时各页重新提交自己保留的完整位移和视口留位，不重建浏览器或聊天。

`createDecisionSession` 持有原协议与草稿状态，DOM wrapper 和原生程序层共用它。`conversation.human_reply` 只接受当前私聊的真实持久 Agent、owner、generation、token 与版本。普通联系人不因使用共同界面获得浏览器或母体管理权限。程序新增 human 默认仅迁移未编辑的旧官方列表，一次迁移后尊重使用者撤权。

## 实际程序的只读投影

共同 work-surface 默认双窗左右，高压最多十二窗。源身份包含持久会话、Agent、代次与调用编号；读取不触发工具重执行。

浏览器回执解析到真实 tab_id 后，Desktop 使用原 browser runtime.previewTarget 与受控 capturePage 获取同一标签页的画面，前后校验标签和导航身份。投影不创建第二浏览器、不转移控制权；页面操作仍走原 Program/browser 服务。尚未完成或不可读的画面不以其他标签替代。

联系人投影从原联系人服务读取公开名字、简介、程序身份和会话状态，跟真实 agents 管理回执关联。它是同源业务投影，保留原联系人页面作为实际编辑入口，不是联系人页整幅屏幕镜像，也不复制提示词或私聊正文。

私聊 terminal_read 复用原 group_terminal_read 的回执解析与日志读取器，按原私聊或群成员解析归属；只读保留日志，不创建 Shell、不接受任意路径或系统 PID。

隐藏时同步停止轮询并释放媒体与读取代次；恢复只读取当前事实。关闭、切会话、程序解绑或迟到导航不得把旧结果发布到新表面。原生窗口的实际显隐、布局与缩放仍须 AIDEBUG 实测，静态节点存在不代表验收。

真实窗口最小化必须同时核原生状态与 `document.hidden`，并测试一份跨隐藏返回的真实投影回执：恢复前不得重新发布媒体，恢复后不能重发模型或工具。浏览器原生容器、会话侧栏、聊天原生层须使用同一有效避让，不能只核各自 DOM。自动驱动的焦点模拟必须由所属协议会话暂停后再观察真实隐藏。

## 浏览器实例与控制

浏览器登录身份profile和工作实例group_id分开。原生浏览器与其固定Navi用program/browser范围，OS的Eyra/Navi会话各用自己的持久范围；工具调用不隐式抢其他会话或全局活动页。open可指定group_id增加标签，new_instance:true新开实例；同范围同身份存在多个实例而未指定时明确拒绝，不任选。每实例动作串行、不同实例可并行，原owner/取消/控制代次与快照校验保留。

Agent默认控制所属实例，无接管/交还按钮。用户在原页面直接操作时自动使旧Agent动作失效；已受理的新消息交回Agent并要求新快照。标签总数不以投影预算封顶；原生可见实例最多十二个，默认空间充足时左右排列，隐藏投影停止采图但不会停止任务。程序、聊天和投影复用原运行服务，不复制执行。
