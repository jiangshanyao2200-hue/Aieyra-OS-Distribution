# 开发者阅读与交付范围

长期共同开发按[长期协作开发](长期协作开发.md)执行，新程序按[程序标准链路](程序标准链路.md)接入；[代码链索引](代码链索引.json)由code-atlas.py维护。先读当前任务和最近CODEMAP，按show/chain查影响，修改后refresh/check。任务原话、个人偏好和接续状态保留在私人工作记录。

[AI开发工具](AI开发工具.md)给出有界上下文、追加任务检查点和真实观察分诊的命令、输入格式与失效处理。提供完整源码/工具的主工程可直接使用；部分公开包先核distribution缺项，不把导航文档当可执行能力。

从 [根协约](../AGENTS.md)、[导航](../INDEX.md) 和 [工程地图](工程地图.md) 找到职责，再读对应目录的 AGENTS.md、真实入口和消费者。专题地图解释调用关系；模块状态不等于工单验收状态。

## 本机共同开发

在 Together 里选定权威项目，由负责人确认 Git 根目录、源码范围和阶段备份。项目的 `Aieyra Link SPACE` 保存协作环境和本地阶段包。基线核对跟踪文件与私人资料排除项，用 `git bundle verify` 检查备份能否作为恢复来源。

工位领取任务后，使用自己的原生会话和任务工作树。记录起始提交、结果提交和复验依据，交给对应负责人核对。合并前核对主工作树状态。合并有冲突时在任务工作树保留冲突和未提交改动，供负责人继续处理。

开发源码由 `scripts/export-source.py` 生成，逐文件文档清单在 `Contracts/development-documents.json`。Windows完整包、独立Link和macOS软件包也使用同一文档清单，按各自实际库存生成地图的文件可用性记录。只纳入明确列出的协约、规范和当前专题，不递归公开整个 docs、AIDEBUG、Prompt、Config 或运行目录。根协约和导航使用公开模板，私有阶段台账、用户原文和证据不复制。

导出的机器地图保留完整工程模块记录，并在 `distribution` 中逐模块记录未随此包提供的源码入口、协约或文档。Markdown 中这些目标显示“未随开发包提供”和原相对路径；该提示只说明交付范围，不说明功能已经完成、删除或不可用。内部 AIDEBUG 代码、独立 Control/Link 配套和历史资料可能不在当前公开源码清单内，不能声称已随包交付或直接运行缺失脚本。原工程地图与文档不因此被重写成另一套工程。

在完整主工程执行 `python -B scripts/check-project-map.py` 核对原地图；在完整开发源码包执行 `python -B scripts/development-docs.py --root .` 核对地图的交付范围和项目 Markdown 本地链接，公开模板按其生成目标解析相对链接。隐私检查继续使用 `python -B scripts/public-privacy.py --root .`。这些脚本命令只适用于提供相应脚本及依赖的完整开发源码包；Windows、独立Link和macOS软件包提供导航文档，不声称附带全部开发检查工具。运行依赖的原始文档与签名包载荷保持原字节。路径和隐私检查不代替编译、测试、GUI 实看或真实供应商验证。

Core构建准备时在创建来源收据前核对已选公开包的声明载荷，复用导出的SHA256/size校验。发现缺文件或摘要不符即停止，不会自动重写manifest；修改包内呈现或实现后须按模块协约维护版本与清单。预检只使用公开来源库存，不读取清单额外指向的路径，也不代替Core的签名、官方身份或兼容准入。

新增或移动模块时，同步实际实现、最近协约、工程地图、文档精确清单与消费者。签名包内不插入 AGENTS.md；由包外协约逐包说明，避免改变载荷摘要。运行依赖和第三方库由上层协约说明，不能因目录整理删除锁、许可或恢复证据。

桌面源码和新运行入口统一为 `Client/Desktop`。从根 `Desktop` 布局迁移时使用完整软件包：旧版本更新器不能直接识别新目录，不能把增量更新解释为跨布局迁移。新更新器可读取旧签名基线中四项精确 bootstrap 来源并恢复到原脚本目标；新旧来源命中同一目标、摘要不符或签名无效仍拒绝。运行中的旧实例继续使用其原路径，须等自然退出并核对消费者后再退役旧运行文件。未改版官方 Program 依赖的旧公共资源由 `Contracts/desktop-compatibility.json` 逐文件固定摘要，整包保留这些资源。
