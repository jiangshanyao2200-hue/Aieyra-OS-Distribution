# Control Electron 壳 · 工作协约

遵循[根协约](../../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：`main.cjs`（当前工作树未提供：`main.cjs`）、`preload.cjs`（当前工作树未提供：`preload.cjs`）、`os-owner-pipe.cjs`（当前工作树未提供：`os-owner-pipe.cjs`）、`README.md`（当前工作树未提供：`README.md`）。

职责：提供独立Control壳、登录/通知与OS所有者管道，加载同一web页面，不复制协同业务。

依赖与接口：路径和进程能力由受控平台桥注入；通知账、owner管道和服务ACK分别表示不同阶段。

资料与状态：身份与凭据在外部私有根，窗口关闭/进程退出按租约交接；不抢焦点或读取剪贴板完成验收。

开发与验收：对应tests/desktop-notifications与package脚本检查，Windows实际原生消息/重开需串行实测；不要自动重开用户GUI。

兼容与交接：OS托管与独立模式保留共同所有者边界；消息可见不冒称模型已收到或执行。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
