# Control Android 客户端 · 工作协约

遵循[根协约](../../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：`README.md`（当前工作树未提供：`README.md`）、`build.gradle`（当前工作树未提供：`app/build.gradle`）、`README.md`（当前工作树未提供：`tests/README.md`）。

职责：保留Control Android通道、登录/通知和办公室界面源码及历史debug APK；独立构建入口当前明确拒绝执行，属于兼容资料，不是Client/Mobile中尚未实现的OS手机App。app是源码，gradle是构建工具，artifacts是历史产物。

依赖与接口：使用同一Control服务与正式身份/投递协议，手机前后台不能复制任务执行或静默重发未知操作。

资料与状态：设备身份/密钥留在设备私有存储；历史APK/证据不因整理直接删除，不向第三方Gradle/产物目录散放AGENTS。

开发与验收：mobile/README区分历史alpha命令和现行阻断，tests说明保留真实设备未验项；不为文档整理重新启用构建。未来恢复发行时再串行验Gradle/设备，Android CLI通过不等于手机UI。

兼容与交接：服务版本/设备撤销/断线恢复保持兼容，实际设备和合成接口结果分别记录。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
