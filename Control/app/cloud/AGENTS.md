# Control 云服务源码 · 工作协约

遵循[根协约](../../../AGENTS.md)；当前职责与迁移边界见[工程地图](../../../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：`server.py`（当前工作树未提供：`server.py`）、`matrix_store.py`（当前工作树未提供：`matrix_store.py`）、`feedback_store.py`（当前工作树未提供：`feedback_store.py`）。

职责：本目录为云API/站点、反馈和Matrix存储实现；site为随服务页面，不是OS主工程本机Control状态库。

依赖与接口：沿正式云协议鉴权，论坛/反馈/公开发布不能从本地文档或历史工单自动获得授权。

资料与状态：运行数据库和云凭据在服务器私有根，不进源码、样板或回执；本机与生产云资料不互借。

开发与验收：Python-B用本地合成状态运行对应云测试，实际公网只读与发布另按用户授权；不得因本协约自动SSH、写生产或部署。

兼容与交接：API/schema变化核对OS/Control消费者、旧客户端和错误回执；合成本地通过不等于已上线。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。
