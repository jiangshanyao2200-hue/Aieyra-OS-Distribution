# 配置与公共资源边界 · 工作协约

遵循[根协约](../AGENTS.md)；当前职责与迁移边界见[工程地图](../docs/工程地图.md)。本文件覆盖本目录中没有更近协约的自有子目录，测试、样例资产和第三方依赖不因此成为独立执行模块。

入口：[默认设置.json](默认设置.json)、[运行参数.json](运行参数.json)、[提示词索引.json](提示词索引.json)。

职责：公共默认、release_stage、提示词逻辑索引和模型/终端配色资料在此维护；config.json及个人外观等是私人活动配置，不因文档整理改写。

依赖与接口：Core与Desktop经共同路径和配置CAS读写；运行参数是阶段功能唯一开关，变动同步docs/阶段性隐藏功能清单。

资料与状态：Key、连接、私人覆盖和备份不纳入公开包；不能扫描或打印私人值生成工程地图。

开发与验收：公共结构改动验证Core/设置服务/索引消费者及public-privacy；私人活动文件不为验收复位，不用历史哈希覆盖用户新修改。

兼容与交接：缺默认按正式迁移规则补齐，已有空覆盖保留；功能隐藏不能因旧测试或样板自动重开。 修改接口时一起核对调用者、交付清单和对应专题地图；未实际验证的范围保持未验，不以目录存在或安装成功代替运行验收。


os_first_ring精确开放原浏览器、联系人、汉堡及OS会话；旧land_core_only已退役，link_situation仍独立控制远端自动加入。当前公开[阶段清单](../docs/阶段性隐藏功能清单.md)与[一环设计](../docs/一环运行与投影.md)必须同步。
